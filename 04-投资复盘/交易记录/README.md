# 交易记录

## 用途
存放每笔交易的详细记录，包括买卖时间、价格、数量、手续费，用于后续绩效分析和税务计算。

## 推荐文件命名规范
```
YYYYMMDD_交易记录.md / .xlsx
```
- 示例：`20260731_交易记录.xlsx`

## 建议记录字段
- 交易日期 & 时间
- 股票代码 & 名称
- 买卖方向（买入/卖出）
- 成交价格 & 数量
- 手续费 & 印花税
- 交易理由摘要
- 盈亏金额（卖出时填写）
