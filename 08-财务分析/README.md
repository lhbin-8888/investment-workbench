# 财务分析 · 个股财务数据分析模块

> 投研工作台「财务分析」板块。参照《个股财务数据分析.docx》的核心框架与"中国巨石"案例模板，
> 输入**个股名称或代码**，自动拉取真实财务数据，生成结构化分析报告并以网页展示。

## 一、对应文档框架

| 文档核心板块 | 本模块实现 |
|---|---|
| 五大报表核心指标（利润表/资产负债表/现金流量表） | 自动计算 毛利率、净利率、ROE、营收/净利同比、资产负债率、流动比率、自由现金流、净现比、收入现金比、应收/存货周转率、EPS |
| 财务健康评判体系（健康特征 + 5 类警惕信号） | 核心数据表 + 财务健康度核查表，按文档评判标准自动上色（优秀/卓越/健康/警惕） |
| 发展潜力维度（成长性 CAGR / 行业地位 / 护城河） | 年报趋势表 + CAGR + 行业横向对比（毛利率/净利率/资产负债率/排名/同业龙头） |
| 实操四步法（排除陷阱→指标对比→成长验证→估值匹配） | 报告七段式结构即按此逻辑组织 |
| 案例模板（中国巨石 600176） | 报告章节：核心数据→成长性→健康度核查→行业对比→估值→综合结论(星级评分)→跟踪清单 |

## 二、启动方式

> **架构要点**：板块内的分析器 `fa.html` 是**纯前端页面**——浏览器直连东方财富 + 腾讯财经拉取数据、本地计算指标、渲染报告，**不依赖任何后端进程**。因此本地 `start.bat`、线上静态托管（GitHub Pages / 对象存储等）、甚至直接双击 HTML 文件都能正常出报告。

### 方式 A：随投研工作台一起启动（推荐，已接入财务分析板块）
直接双击 `D:\投研工作台\start.bat`：
- 工作台首页：http://localhost:8848/index.html
- 在左侧导航「投研研究 → **行业与个股分析 → 财务分析**」点击，即在原文档区以 iframe 嵌入 `08-财务分析/fa.html`（已合并原"财务分析工具"独立入口），输入名称或代码即可出报告；该区下方保留「财务分析功能模板」「模块说明/命名规范」文档链接
- 注意：若你的线上工作台是**纯静态部署**，请务必确保 `08-财务分析/fa.html` 一并部署（它是前端页面，随仓库走，无需后端）

### 方式 B：命令行直接生成报告（基于 Python 引擎，用于批量/离线/导出 PDF）
```bash
cd D:\投研工作台\08-财务分析
python stock_analyzer.py 600176            # 生成静态 HTML 报告
python stock_analyzer.py 中国巨石           # 支持名称输入
python stock_analyzer.py 600176 --pdf      # 同时导出 PDF（同目录 .pdf，调用本机 Edge 无头打印）
python stock_analyzer.py 600176 --out D:\报告
```
`stock_analyzer.py` 仍保留后端服务模式（`--serve`）与 `/fa/` 路由作为兼容入口，但**板块 iframe 已改用纯前端 `fa.html`**，线上无需该后端。

### 导出 PDF
- **网页端（推荐，线上可用）**：报告页右上角「⬇ 导出 PDF」按钮 → 调用浏览器打印（`window.print()`），另存为 PDF 即可；已内置打印样式
- **命令行（本地）**：加 `--pdf` 参数（如方式 B 所示），依赖本机 Edge/Chrome 无头打印，与 `tools/md2pdf.py` 同口径
- **PDF 版式增强**：导出的 PDF 自动包含 **封面页**（公司名称/代码/行业/报告期/评分/生成时间/免责声明）、**每页页眉**（投研工作台标识 + 标的 + 日期）与**每页对角线水印**（仅供研究参考）；屏幕交互视图保持干净，上述元素仅在打印/导出时显示

> 依赖：纯前端 `fa.html` 零依赖（浏览器原生 fetch，无需 Key、无需装包）；`stock_analyzer.py` 仅 Python 标准库（urllib / ssl / subprocess）。

## 三、数据来源（均无需 Key）

- **东方财富** `datacenter-web.eastmoney.com`：利润表 / 资产负债表 / 现金流量表 / 同业数据
- **腾讯财经** `qt.gtimg.cn`：实时行情、PE(TTM)、总市值、换手率
- 名称 → 代码：通过东方财富财务接口按证券简称精确反查

## 四、计算与口径说明

- 毛利率 =（营收 − 营业成本）/ 营收；净利率 = 归母净利润 / 营收
- ROE = 归母净利润 / 平均净资产（期初取上一期资产负债表权益）；报告中"ROE(年化)"按报告期类型折算（半年×2、单季×4）以便与"ROE≥15%为优秀"阈值比较
- 净现比 = 经营现金流净额 / 归母净利润；收入现金比 = 销售商品收到现金 / 营收
- 自由现金流 = 经营现金流净额 − 购建固定资产等现金流出
- PB = 总市值 / 净资产；EPS = 归母净利润 /（总市值÷股价）
- **行业横向对比口径**：取同东财行业全部上市公司，剔除标的自身后，在**盈利企业**中取**中位数**作为同业基准（避免亏损/平板玻璃企业拉低均值），排名含自身
- **综合评分**：依据文档评判标准逐项判定（盈利/偿债/现金流/成长/行业地位），正向满分归一化为 0–5 星

## 五、已知限制

- 证券简称需为**精确简称**（如"中国巨石"），不支持模糊昵称；不确定时直接输入 6 位代码
- 速动比率所需的"流动资产/流动负债"明细东财该接口未披露，报告以流动比率为准，速动比率暂未单列
- 研发投入占比、分红明细不在三大报表主表内，未自动抓取（可在报告中手工补充）
- 行情/估值为查询时刻实时数据，可能与文档案例的历史快照不同
- 部分 ST / 北交所标的数据覆盖可能不全
