## 三、产业链焦点（断点分析）

> 方法：画链 → 锚定龙头 → 下钻物理瓶颈 → 卡口四条件（不可替代 / 供给刚性 / 寡头垄断 / 无人看见）→ 辨短缺性质 → 验定价 → 风控 → 事件三问。

**1. 画链（电力产业链全景）**
- 上游：一次能源（煤炭 / 天然气 / 铀·核燃料 / 水·风·光自然资源）、电力设备（发电主机、核岛主设备、变压器/开关/电缆、特高压）、电网基础设施。
- 中游：发电（水电 / 核电 / 火电 / 风电 / 光伏 / 绿电运营）、输电、配电、售电。
- 下游：终端用电（工业、居民、商业、**AI 数据中心、电动车**等高增负荷）。

**2. 锚定龙头（从需求端入口）**
代表股样本 7 只全部是**发电运营商**（水电：长电/华能水电/国投/川投；核电：中国核电；火电：华能国际；新能源运营：三峡能源）。需求端真正驱动来自下游用电侧（AI 算力耗电、电动车、夏季制冷负荷刚性增长）。龙头视角：长江电力（全球最大水电上市公司、市值近 7000 亿，水电绝对龙头）、中国核电（核电双寡头之一）。龙头只是入口——往下钻才能找到真瓶颈。

**3. 下钻物理瓶颈（龙头 → 资源 → 设备 → 电网）**
- 水电：核心约束是**优质水电坝址（水能资源）**——雅砻江、金沙江、长江干流等优良坝址已基本开发殆尽，新建大型水电站建设周期 10 年+，物理上不可再生、不可复制。
- 核电：核心约束在**核岛主设备（反应堆压力容器、蒸汽发生器，AP1000 / 华龙一号）**，由东方电气、上海电气、哈尔滨电气三家寡头制造；叠加**机组核准**由国家刚性审批、建设周期 5–6 年；核燃料（铀）供给全球寡头。
- 火电：主机与灵活性改造设备已成熟，非瓶颈。
- 风/光：风机、组件早已**产能过剩、价格内卷**，设备端不是瓶颈；真正的瓶颈在**并网消纳与特高压外送（电网侧）**。
- 电网侧：新能源大基地的外送依赖特高压，投资为政策刚性、核准制，主设备（特变/中国西电/保变）寡头。

**4. 卡口四条件判定（对撞到的瓶颈逐一过筛）**

| 候选瓶颈环节 | 不可替代 | 供给刚性 | 寡头垄断 | 无人看见 | 判定 |
| --- | --- | --- | --- | --- | --- |
| 优质水电/核电存量资源（坝址、矿权） | ✓ | ✓（新坝址枯竭、开发10年+） | ✓（央企分流域垄断） | ✗（长电/华能已被全市场公认核心资产） | **已定价，非真卡口**——防御底仓，超额有限 |
| 核电主设备（堆容器/蒸汽发生器） | ✓ | ✓（制造资质壁垒极高、扩产慢） | ✓（东电/上电/哈电三家） | 部分（相对运营商仍被低估） | **真卡口候选**——核准加速+资质壁垒+产能刚性 |
| 特高压/电网消纳 | ✓ | ✓（核准制、建设周期长） | ✓（设备寡头） | 部分 | **次卡口**——新能源外送刚需，政策强驱动 |
| 风/光组件 | ✗（同质化、可替代） | ✗（产能充足、扩产快） | ✗（充分竞争） | ✗ | **跳过**——产能过剩、价格压力 |

**5. 辨短缺性质**
- 水电坝址 / 核电设备订单：属**长期结构性短缺**（资源枯竭 + 资质壁垒 + 长建设周期），对应趋势性行情，非一日游。
- 风/光组件短缺（若有）：属**短期临时性**，且当前实为产能过剩，直接排除炒作逻辑。

**6. 验定价（故事 vs 产业事实）**
- 运营商估值：长电 PE 19.2、华能水电 22.0、中国核电 25.7、国投 16.0、川投 16.6、华能国际 9.2。整体不贵，但"稀缺水电"已被充分认知，属**防御性收租资产**而非预期差来源。
- 核电设备与电网设备：相对发电运营商仍处于**预期差区间**（核准加速→订单饱满→产能刚性，但市场焦点多停留在运营商），更贴近"产业事实型行情"。
- 需求侧硬数据支撑：AI 数据中心用电、电动车保有量、迎峰度夏负荷均为**可核对的真实需求增长**，非概念叙事。

**7. 风控**
不重仓单一赛道/单一标的；电力运营商波动相对小，但核电/新能源运营受政策与来水/利用小时影响，单标的接受 20%–30% 最大回撤，换取下行有限、上行放开的赔率结构。

**8. 事件三问（近期催化映射产业链机会）**
- 核电新机组核准落地 → 核心受益是**核岛主设备制造**（东电/上电/哈电），产能刚性环节率先扛不住需求、订单外溢。
- 迎峰度夏 / 极端天气 → **水电来水、火电容量电价、灵活性改造补偿**受益；三峡能源等新能源运营受消纳约束。
- 绿电入市 / 特高压开工 → 利好**电网侧特高压与具备外送能力的清洁电力运营商**。

**▶ 产业链焦点结论（定性）**
本周电力板块的逆势走强，本质是大盘风险偏好回落后资金拥抱"低估值 + 高股息 + 稀缺资源"的防御属性，代表股（运营商）是**收租型存量资产**，其"优质资源稀缺性"已被充分定价（非无人看见，故不构成真卡口）。真正尚未被全市场充分挖掘的**真卡口 / 次卡口在产业链上游与电网侧**：①**核电主设备制造**（核准加速 × 资质壁垒 × 产能刚性，四条件中三强、相对低估，是真卡口候选）；②**特高压与电网消纳能力**（新能源大基地外送刚需、政策刚性，次卡口）；③水电/核电的**优质资源本身**是结构性稀缺但已定价，宜作底仓而非追高。已定价跳过项：风/光组件（产能过剩）。
