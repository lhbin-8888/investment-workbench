## 三、产业链结构图与关键环节分析

```
上游（卡口区）   细胞培养基 / 层析介质 / 重组蛋白与酶 / 一次性耗材
      ↓
中游             CXO·CDMO / 原料药 / 生物药原液与制剂生产
      ↓
下游             创新药企 / 疫苗企业 / 医疗机构与患者
```

### 3.1 断点分析路径（八步）

1. **画链**：上游耗材—中游生产—下游用药三层画全，先不看涨跌。
2. **锚定需求端龙头**：创新药与疫苗放量是总需求源头（恒瑞医药、百济神州、智飞生物等）。
3. **逐层下钻**：创新药放量 → CDMO 产能 → 培养基与层析介质 → 高纯度重组蛋白与酶。
4. **物理四问**：逐层追问寡头、扩产周期、可替代性、下游必用性（见下表）。
5. **卡口四条件**：不可替代、供给刚性、寡头垄断、无人看见，四中才算真卡口。
6. **辨短缺性质**：培养基与层析介质属长期结构性短缺，非短期缺货。
7. **验定价**：用本周资金数据检验市场是否已认可该逻辑。
8. **风控与事件三问**：不重仓单一赛道；若 BD 订单/获批利好出现，追问其上游耗材配套由谁承接。

## 四、瓶颈 / 卡口环节判断

| 环节 | 不可替代 | 供给刚性 | 寡头垄断 | 无人看见 | 判定 |
| --- | --- | --- | --- | --- | --- |
| 层析介质 | 是 | 是 | 是（全球三家） | 是 | **真卡口** |
| 细胞培养基 | 是 | 是 | 是（全球三家） | 是 | **真卡口** |
| 重组蛋白与酶 | 是 | 中 | 部分 | 是 | 准卡口 |
| CXO / CDMO | 否 | 否 | 否 | 否 | 非卡口 |
| 化学制剂 | 否 | 否 | 否 | 否 | 非卡口 |

**短缺性质判断**：**长期结构性短缺**。培养基配方与层析介质配基、孔径控制属隐性工艺（know-how），客户变更供应商须重做工艺验证与注册申报（约 12–24 个月），国际巨头扩产也无法快速填平。

**定价验证**：本周资金再度流出（创新药 -10.06 亿），医药连续两周无涨停个股，**卡口环节（层析介质、培养基）完全没有专属资金定价**——“无人看见”条件仍然成立，预期差维持，但右侧信号（资金转正）暂被证伪。

**最紧缺环节结论**：生命科学上游核心耗材——**细胞培养基、层析介质、高纯度重组蛋白与酶**的国产替代（结构性结论连续五期未变）。

## 五、预期差与投资机会提示

1. **抗跌未定价**：生物疫苗 -1.22% 为七链相关概念跌幅最小，医药的防御属性在普跌日已显形，但资金尚未认领——防御风格若延续（本周涨幅前列为白酒/煤炭/焦炭），医药是下一个潜在承接方向。
2. **资金转正是唯一右侧信号**：上周转正、本周证伪，建议以“创新药概念主力净流入连续两周为正 + 上游试剂标的进领涨前排”作为重新介入的确认条件。
3. **个股线索**：翰宇药业放量 +0.18 亿、迪哲医药-U 逆势，属点状资金试探，未成体系。
4. **卡口环节仍无定价**：层析介质/培养基国产厂商未见专属资金，低拥挤状态延续，适合跟踪验证进度而非追价。
