## 二、资金面动向

- **行业级流入、概念级流出并存**：半导体行业 +3.49 亿、封测 +2.38 亿、设备 +1.53 亿为真实增量；国产芯片 -1.18 亿、半导体概念 -1.40 亿说明泛概念筹码在节前兑现，资金向细分子行业收缩。
- **封测最确定**：通富微电单票 +3.02 亿居全场前列，先进封装概念 -0.25 亿说明资金只买龙头不买板块。
- **材料端连续冷落**：光刻胶 -0.36 亿、无领涨属性；上周材料端（电子化学品）同样净流出。材料卡口连续两周无资金定价。
- **涨停池佐证**：全市场 23 家涨停中无半导体标的，情绪面缺席，资金行为以机构配置型为主。
- **结论**：半导体呈"机构买制造封测、游资不参与、材料无人问"的配置型行情，波动小、预期差囤积在材料与零部件环节。

### 3.1 断点分析路径（八步）

1. **画链**：按上游材料与设备—中游设计制造封测—下游应用三层画全。
2. **锚定需求端龙头**：中芯国际、华虹的资本开支是材料与设备的直接需求源；AI 服务器与汽车电子是增量需求。
3. **逐层下钻**：晶圆扩产 → 设备采购 → 设备零部件 → 材料消耗 → 高纯石英砂 / 电子级多晶硅 / 高纯金属。
4. **物理四问**：见下表。
5. **卡口四条件**：逐环节打分。
6. **辨短缺性质**：材料端的短缺属长期结构性（验证周期 + 提纯工艺壁垒）。
7. **验定价**：用本周资金与涨幅验证。
8. **风控**：单一环节仓位上限，单标的可承受 20%–30% 回撤。

**物理四问的核心答案**：材料端（ArF 光刻胶、高纯石英砂、电子级多晶硅）的壁垒不只是产能，而是**提纯工艺的极限与客户验证周期（12–24 个月）**；设备零部件（静电吸盘、射频电源）则是**精密加工与材料配方的双重壁垒**，且更换供应商需要整机厂重新验证，取证周期极长。

## 四、瓶颈 / 卡口环节判断

| 环节 | 不可替代 | 供给刚性 | 寡头垄断 | 无人看见 | 判定 |

| 设备核心零部件 | 是 | 是 | 是 | 是 | **真卡口** |
| 晶圆制造产能 | 是 | 是 | 是 | 部分 | 卡口（受管制约束） |

| 芯片设计 | 否 | 否 | 否 | 否 | 非卡口 |

**短缺性质判断**：**长期结构性短缺**。材料与零部件的验证周期与提纯/精密加工工艺属物理与工艺硬约束，海外寡头扩产意愿低（因份额稳定），国产替代是最确定的中期主线。

**定价验证**：本周封测（+2.38 亿）、设备（+1.53 亿）、制造获得真实流入，而光刻胶 -0.36 亿、光刻机 -2.00 亿、材料端连续两周无专属资金。**被买入的是景气（产能），未被买入的是瓶颈（材料与零部件）**，预期差持续累积。

**最紧缺环节结论**：**半导体材料（高纯石英、光刻胶、电子特气、靶材）与设备核心零部件（静电吸盘、射频电源、真空阀）的国产替代**。

## 五、预期差与投资机会提示

1. **材料端是第一顺位**：连续两周无资金定价，一旦晶圆厂稼动率与国产验证进度出现催化，材料是"资金轮动下一站"的高概率方向。
2. **设备零部件**：静电吸盘、射频电源、真空阀等具整机厂认证壁垒，进入供应链后粘性极强，属长坡厚雪。
3. **制造与封测跟随配置**：晶合集成、通富微电模式——资金当前的主战场，波动小但已部分定价，作为底仓而非弹性仓。
4. **节奏提示**：节前缩量、情绪缺席，正是低吸卡口环节的窗口期；避免追涨连涨的封测龙头。

## 六、风险提示

- 海外半导体设备与材料出口管制进一步收紧；
- 晶圆厂资本开支低于预期，材料与设备订单延后；
- 材料国产验证进度不及预期，业绩兑现慢于股价；
- 封测制造涨幅积累后，板块整体回调可能拖累全链；
- 本报告为盘中数据快照，午后及收盘数据可能显著偏离。
