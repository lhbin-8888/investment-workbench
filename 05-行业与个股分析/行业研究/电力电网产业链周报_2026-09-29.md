**个股层面**：国轩高科 +10.01% 涨停（+2.75 亿，储能电池）、金龙羽 +10.01% 涨停（+0.91 亿，电缆）、金百泽 +9.60%、麦格米特 +2.47%（+1.33 亿，电源）、华自科技 +4.23%、申昊科技 +3.96%（电力巡检）、经纬辉开 +3.33%（+0.15 亿）；涨停池中电力 2 家（浙江新能 **2 连板**、封单 2.46 亿）、电网设备 1 家。

关键观察：**资金买的是"电"的景气外溢（储能、电缆、电源），而不是电网设备的物理卡口**——取向硅钢、绝缘件等卡口环节依然不在资金视野内。

## 二、资金面动向

- **总量转正是最大变化**：智能电网 +2.22 亿（上周 -7.43 亿）、电力设备 +3.27 亿（行业第四）、电力 +1.36 亿，电网链资金全面回暖，方向信号明确。
- **结构偏储能与电缆**：储能概念 +3.56 亿、国轩高科（+2.75 亿）与金龙羽（+0.91 亿）双涨停；特高压 -3.95 亿说明市场不买"大基建"逻辑，买"新能源消纳与配网"逻辑。
- **情绪高度有限但存在**：浙江新能 2 连板（封单 2.46 亿）是电网链目前最高连板，全市场 23 家涨停中电网相关占 3 席，情绪温和。
- **结论**：电网板块从"资金候补"升级为"资金流入方向"，但增量资金集中在储能/电缆等外溢环节，真正的物理卡口（材料端）仍未定价，属于"方向已来、标的未切换"的阶段。

## 三、产业链结构图与关键环节分析

```
上游（卡口区）   高牌号取向硅钢 / 环氧浇注绝缘件 / 高压套管 / 铜 / IGBT·SiC 器件 / 智能电表芯片
      ↓
中游             变压器 / 开关柜与GIS / 换流阀 / 电缆 / 铁塔 / 配电自动化终端
      ↓
下游             国家电网与南网招标（特高压/配网）/ 新能源电站并网 / 工商业与居民用电
```

### 3.1 断点分析路径（八步）

1. **画链**：按上游材料与器件—中游输变电设备—下游电网投资三层画全。
2. **锚定需求端龙头**：国家电网与南方电网的年度投资计划（特高压 + 配网改造）是总需求源；A 股入口为国电南瑞、许继电气、平高电气。
3. **逐层下钻**：特高压与配网投资 → 变压器/开关 → 高牌号取向硅钢 → 二次再结晶轧制工艺；另一路径为套管与环氧浇注绝缘件。
4. **物理四问**：见下表。
5. **卡口四条件**：逐环节打分。
6. **辨短缺性质**：取向硅钢与高压绝缘件的短缺属长期结构性（工艺 + 设备双约束）。
7. **验定价**：用本周资金与涨幅验证。
8. **风控**：单标的可承受 20%–30% 回撤，不重仓单一环节。

### 3.2 逐层下钻与物理四问

| 下钻层级 | 代表环节 | 谁是寡头/唯一 | 扩产要多久 | 可否替代 | 下游必用 | 判定 |
| --- | --- | --- | --- | --- | --- | --- |
| 第一层 | 配电自动化终端 | 分散，国电南瑞等领先 | 0.5–1 年 | 可替代 | 是 | 非卡口 |
| 第二层 | 开关柜 / GIS | 平高、许继等，集中度中高 | 1–1.5 年 | 部分可替代 | 是 | 准卡口 |
| 第三层 | 电缆 | 分布广，龙头集中度中 | 1 年 | 可替代 | 是 | 非卡口 |
| 第四层 | 变压器 | 特变、保变等，集中度中高 | 1–1.5 年 | 部分可替代 | 是 | 准卡口 |
| 第五层 | 高牌号取向硅钢 | 宝钢、首钢等少数钢厂可产 | 2–3 年（轧机+工艺） | **不可替代** | 是 | **硬卡口** |
| 第六层 | 高压套管 / 环氧浇注绝缘件 | 海外+国内少数厂商 | 1.5–2.5 年 | 不可替代 | 是 | **真卡口** |

**物理四问的核心答案**：高牌号取向硅钢（Hi-B）依赖**二次再结晶的轧制与退火工艺**，且高牌号产品对轧机精度与工艺窗口要求苛刻，全球仅少数钢厂可稳定量产，新增产能需 2–3 年；高压套管与环氧浇注绝缘件的壁垒在于**绝缘配合设计与长期运行可靠性验证**，属物理与工艺双约束。

## 四、瓶颈 / 卡口环节判断

| 环节 | 不可替代 | 供给刚性 | 寡头垄断 | 无人看见 | 判定 |
| --- | --- | --- | --- | --- | --- |
| 高牌号取向硅钢 | 是 | 是（轧机+工艺） | 是 | 是 | **真卡口** |
| 高压套管 / 绝缘件 | 是 | 是 | 是 | 是 | **真卡口** |

| 储能电池 / 电缆 | 否 | 否 | 否 | 否（资金已扎堆） | 非卡口 |

**短缺性质判断**：**长期结构性短缺**。取向硅钢与绝缘件的工艺积累无法通过资本开支短期复制；同时电网投资具备政策性长周期属性，需求端稳定。

**定价验证**：本周电网链资金总量转正（智能电网 +2.22 亿、电力设备行业口径 +3.27 亿），但增量资金全部落在储能（+3.56 亿）、电缆（金龙羽涨停）等非卡口环节，特高压反而流出 3.95 亿。**方向已确认、卡口未被定价**——这正是预期差尚未兑现的状态，等资金从"电的景气"切换到"电网的材料"。

**最紧缺环节结论**：**高牌号取向硅钢与高压套管 / 环氧浇注绝缘件**，其次为电力电子器件（IGBT/SiC）国产替代。

## 五、预期差与投资机会提示

1. **材料端是第一顺位**：资金已确认电网方向，但标的集中在储能电缆；高牌号取向硅钢与高压绝缘件的国产替代是"下一站"高概率方向，宜提前低吸。
2. **储能与电缆属跟随行情**：国轩高科、金龙羽已获资金定价，弹性存在但逻辑属外溢，不宜作为电网主逻辑重仓。
3. **一次设备出海**：变压器与开关的海外订单是中期主线，与取向硅钢供给形成上下游联动。
4. **节奏提示**：板块资金方向刚转正、量能温和，节后若电力设备行业口径资金继续放大，可视为加仓信号；连板股（浙江新能 2 板）情绪高度有限，注意断板风险。

## 六、风险提示

- 电网投资节奏与招标进度低于预期；
- 取向硅钢与绝缘件国产验证周期长，业绩兑现慢；
- 储能/电缆环节资金扎堆后回撤会拖累板块情绪；
- 节前缩量，资金转正的持续性需节后量能确认；
- 本报告为盘中数据快照，午后及收盘数据可能显著偏离。
