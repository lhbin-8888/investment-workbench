## 二、资金面动向

- **概念整体失血**：智能驾驶 -25.11 亿、汽车芯片 -11.40 亿，与上期（09-29 概念 -2.32 亿）相比流出明显放大，科技退潮波及本链。
- **内部结构**：整车端主力流出（赛力斯 -1.85 亿）、路侧协同端点状流入（金溢 +0.16 亿）——机构对“车”与“路”的态度开始分化。
- **涨停池佐证**：全市场 23 家涨停中无人驾驶相关为 0 家（万里股份为电池逻辑、中马传动为减速器逻辑），本链情绪完全缺席，较上期“广汽涨停 + 雪龙 4 连板”的情绪高位显著降温。
- **结论**：链内情绪从整车端反转行情退潮为观望，路侧基础设施方向出现最早的承接苗头但量级很小。

## 三、产业链结构图与关键环节分析

```
上游（卡口区）   高算力智驾 SoC / 车规 MCU / 线控底盘核心件（冗余转向·制动）
      ↓               激光雷达收发芯片 / 高精度惯导与定位
      ↓
中游             域控制器 / 线控制动·转向总成 / 激光雷达总成 / 摄像头模组
      ↓                 软件与算法（BEV/端到端） / 高精地图与数据闭环
      ↓
下游             整车厂（NOA 量产） / Robotaxi 运营 / 车路协同（路侧基建）
```

### 3.1 断点分析路径（八步）

1. **画链**：芯片—线控—感知—域控—算法—整车/路侧。
2. **锚定需求端龙头**：头部整车厂 NOA 量产车型放量是总需求源头（特斯拉 FSD 入华预期、华为系车型矩阵）。
3. **逐层下钻**：NOA 装车率提升 → 域控制器与智驾 SoC → 线控底盘冗余执行器。
4. **物理四问**：见下表。
5. **卡口四条件**：四中才算真卡口。
6. **辨短缺性质**：ASIL-D 级冗余转向/制动属长期结构性短缺；激光雷达已充分竞争、摄像头成熟，非短缺。
7. **验定价**：本周资金在链内几乎全面撤退，卡口环节无定价。
8. **风控与事件三问**：若 Robotaxi 牌照/量产利好落地，追问线控执行器产能率先扛不住的环节与竞对的 ASIL-D 认证时间差。

## 四、瓶颈 / 卡口环节判断

| 环节 | 不可替代 | 供给刚性 | 寡头垄断 | 无人看见 | 判定 |
| --- | --- | --- | --- | --- | --- |
| 线控转向（冗余 ASIL-D） | 是 | 是（认证+专利壁垒） | 是（外资寡头） | 是 | **真卡口** |
| 线控制动（One-Box） | 是 | 是 | 部分（国产已放量） | 部分 | **真卡口** |
| 高算力智驾 SoC | 是 | 是 | 是 | 否（国产算力叙事已被定价） | 卡口（拥挤） |
| 激光雷达 | 否 | 否 | 双寡头但竞争 | 否 | 非卡口 |
| 域控 / 算法 | 否 | 否 | 否 | 否 | 非卡口 |

**短缺性质判断**：线控底盘（冗余转向/制动）属**长期结构性短缺**——ASIL-D 功能安全认证周期以年计、外资寡头专利与工艺壁垒硬、L3 以上法规强制要求冗余，国产替代一旦通过定点即是 5 年以上订单锁定。

**定价验证**：本周链内 -25.11 亿全面失血，线控底盘国产标的（伯特利等）未见专属资金——**卡口环节无定价**，预期差维持；市场注意力仍停留在整车与 Robotaxi 叙事。

**最紧缺环节结论**：**线控底盘（冗余转向/制动，ASIL-D 认证壁垒）+ 高算力智驾 SoC**；激光雷达非卡口（结构性结论连续五期未变）。

## 五、预期差与投资机会提示

1. **整车情绪退潮后的空窗期**：上期广汽涨停、雪龙 4 连板的整车情绪行情本周证伪（赛力斯放量出货），链内进入观望期——历史上卡口环节的布局窗口恰恰出现在情绪空窗期。
2. **路侧/车路协同的苗头**：多伦科技 +4.54%、金溢科技 +3.38% 获点状资金，若“车路云一体化”试点城市扩围政策落地，路侧基建是政策直连方向，可作为观察仓。
3. **卡口环节的跟踪信号**：线控转向国产厂商的整车定点公告、ASIL-D 认证进度、One-Box 渗透率数据——定点落地是订单与股价的前导。
4. **节奏建议**：概念 -25 亿失血期不抄底整车，等资金回流先看线控与域控，整车留作情绪指标。
