## 二、资金面动向

- **从吸金王到失血王**：CPO -43.92 亿、算力 -38.65 亿、人工智能 -39.43 亿、存储 -33.40 亿、PCB -30.87 亿、液冷 -27.62 亿、数据中心 -29.63 亿，AI 硬件各细分合计流出约 250 亿量级（概念口径有交叉），与上期“全面吸金”形成极致反转。
- **唯一正流入**：集成电路制造行业板 +7.75 亿且是在板块 -2.45% 的下跌中实现的——超大单与大单双正、小单大额流出，典型“机构承接、散户割肉”分歧结构。
- **涨停池佐证**：超声电子（PCB）涨停但封单高达 20.71 亿全场第一，说明 PCB 退潮中仍有资金赌个别标的卡位；AI 应用/语料方向本周无涨停。
- **结论**：AI 链进入“高位筹码派发 + 资金向制造端收敛”阶段，方向从设备/材料/PCB 的多点开花转为制造单点承接。

## 三、产业链结构图与关键环节分析

```
基础层（算力底座）  AI 芯片(GPU/ASIC) / 存储芯片(HBM/DRAM) / 先进封装(CoWoS)
      ↓                  服务器 / 液冷 / IDC 数据中心 / 光模块·CPO / PCB·载板
      ↓
模型层             大模型训练与推理 / 算法与框架 / AI 语料
      ↓
应用层             AI 应用软件 / 智能体 / 行业解决方案
```

### 3.1 断点分析路径（八步）

1. **画链**：芯片—存储—封装—整机—网络—数据中心—模型—应用。
2. **锚定需求端龙头**：大模型训练集群的算力采购是总需求源头。
3. **逐层下钻**：训练放量 → HBM/DRAM → 先进封装产能 → 存储国产链（长鑫/长江存储生态）。
4. **物理四问**：见下表。
5. **卡口四条件**：四中才算真卡口。
6. **辨短缺性质**：HBM 与先进封装属长期结构性短缺；PCB/CPO 上半年的紧张属短期临时性短缺（扩产快），本轮回调正在验证这一判断。
7. **验定价**：本周资金全面撤退，但制造端逆势承接。
8. **风控与事件三问**：若大厂资本开支上修，追问最先断供的环节（HBM 产能）与竞对无法跟进的约束（封装设备与混合键合工艺）。

## 四、瓶颈 / 卡口环节判断

| 环节 | 不可替代 | 供给刚性 | 寡头垄断 | 无人看见 | 判定 |
| --- | --- | --- | --- | --- | --- |
| 存储（HBM/DRAM 国产链） | 是 | 是 | 是 | 部分 | **真卡口** |
| 先进封装（CoWoS 类） | 是 | 是 | 是 | 部分 | **真卡口** |
| AI 芯片（国产算力） | 是 | 是 | 是 | 否 | 卡口（已被广泛定价） |
| 光模块 / CPO | 否 | 否 | 否 | 否 | 非卡口（高位博弈） |
| PCB / 载板 | 否 | 否 | 否 | 否 | 非卡口（退潮确认） |

**短缺性质判断**：存储与先进封装属**长期结构性短缺**（海外寡头供给刚性 + 国产链处于验证放量早期）；PCB、光模块今年上半年的缺货属**短期临时性短缺**，扩产即可填平——本期资金从 PCB/CPO 大幅撤出，正是市场对“临时性短缺”的重定价。

**定价验证**：本周链内资金全面撤退，但集成电路制造 +7.75 亿逆势流入——市场在跌势中把筹码从“弹性环节”（PCB/光模块）向“确定性产能”（制造）收敛；存储设备标的拓荆科技获 +0.53 亿。**卡口环节（存储/先进封装）的国产链仍在获得点状资金，未被完全抛弃。**

**最紧缺环节结论**：**存储国产链（HBM/DRAM）+ 先进封装**；PCB/CPO 进入高位退潮博弈（结构性结论连续五期未变，本期资金面进一步验证）。

## 五、预期差与投资机会提示

1. **制造端分歧是本周最大信号**：-2.45% 下跌中主力净流入 +7.75 亿（机构买、散户卖），若后续收盘口径仍为正，制造/IDM 方向有望成为 AI 链退潮期的避风港与下一轮反弹的先导。
2. **临时性 vs 结构性的重定价已开始**：PCB/CPO 的失血是市场纠正“短期缺货=长期卡口”的误判；存储/先进封装的国产链逻辑未被证伪，回撤后拥挤度下降反而改善赔率。
3. **跟踪信号**：HBM 国产验证进度、先进封装产能利用率、大厂月度资本开支——任一转强即为右侧。
4. **超声电子涨停的高封单**（20.71 亿全场最高）说明资金仍在 PCB 里挑“低位补涨卡位”，属退潮期博弈，不作为趋势依据。
