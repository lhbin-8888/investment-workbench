## 二、资金面动向

- **流出显著放大**：机器人概念 -44.77 亿（上期 -1.54 亿附近）、人形机器人 -17.82 亿，节后科技资金撤退在本链充分体现。
- **结构仍有分化**：机器人执行器仅 -2.36 亿、减速器 -2.88 亿，**硬件执行层流出量级远小于概念整体**，说明撤退资金主要来自概念性的泛机器人标的，核心部件持仓相对稳定。
- **涨停池佐证**：中马传动（汽车零部件/减速器）涨停 1 连板、封单 1.94 亿，是链内唯一涨停标的；海得控制（自动化设备，兼智能电网概念）亦涨停。
- **结论**：链内“泛概念失血、核心部件抗跌、新股获资金”三重分化，属于退潮期典型的筹码再分配。

## 三、产业链结构图与关键环节分析

```
设备层（卡口区） 高精度螺纹磨床 / 超硬磨料砂轮 / 磨削机床数控系统
      ↓
零件层           行星滚柱丝杠 / 谐波减速器 / 无框力矩电机 / 空心杯电机
      ↓
集成层           执行器总成（旋转/直线） / 灵巧手 / 传感器
      ↓
整机层           人形机器人整机厂商（宇树、智元、特斯拉 Optimus 等）
```

### 3.1 断点分析路径（八步）

1. **画链**：设备—零件—集成—整机四层画全，丝杠是本链明星零件，但不是最上游。
2. **锚定需求端龙头**：整机放量预期是总需求源头（特斯拉 Optimus 量产节点、国内整机厂商融资扩产）。
3. **逐层下钻**：丝杠放量 → 磨削加工产能 → **高精度螺纹磨床** → 磨床核心部件与**超硬磨料砂轮**。
4. **物理四问**：见下表，逐层追问。
5. **卡口四条件**：四中才算真卡口。
6. **辨短缺性质**：磨床与砂轮属长期结构性短缺（工艺与设备双重壁垒）。
7. **验定价**：本周设备端无专属资金，零件端仅点状。
8. **风控与事件三问**：若整机订单落地，追问磨床产能率先扛不住的环节与竞对无法跟进的设备约束。

## 四、瓶颈 / 卡口环节判断

| 环节 | 不可替代 | 供给刚性 | 寡头垄断 | 无人看见 | 判定 |
| --- | --- | --- | --- | --- | --- |
| 高精度螺纹磨床 | 是 | 是（交期 2–3 年） | 是 | 部分 | **真卡口** |
| 超硬磨料砂轮 | 是 | 是 | 部分 | 是 | **真卡口** |
| 行星滚柱丝杠 | 是 | 中（扩产快于设备） | 部分 | 否（已被市场充分关注） | 准卡口 |
| 减速器 / 电机 | 否 | 否 | 否 | 否 | 非卡口 |

**短缺性质判断**：**长期结构性短缺**。丝杠的磨削精度受机床母机精度决定，螺纹磨床的扩产受自身铸件、数控系统与装配技工约束，产能释放以年计；且丝杠厂“买机床扩产”的行为反而先利好磨床与砂轮厂商。

**定价验证**：本周设备端（磨床/砂轮）无专属资金流入，丝杠相关概念仍以流出为主；宇树科技-W 逆势 +0.66 亿说明市场只给了“整机稀缺标的”定价，**设备卡口仍未被看见**——预期差维持。

**最紧缺环节结论**：**高精度螺纹磨床 + 超硬磨料砂轮**（设备卡口），行星滚柱丝杠次之（结构性结论连续五期未变）。

## 五、预期差与投资机会提示

1. **退潮期只留“确定性 + 新锚点”**：概念整体 -44.77 亿说明泛机器人筹码在撤退，但执行器/减速器流出量级小、宇树逆势获资金，退潮末端核心持仓稳定是中期积极信号。
2. **设备卡口的跟踪信号**：丝杠厂商扩产公告中“采购螺纹磨床的数量与交期”是最硬的产业数据；磨床厂在手订单与交期披露是前导指标。
3. **中马传动涨停的定位**：属减速器/传动的情绪外溢，非卡口逻辑主升，谨慎追高。
4. **节奏建议**：退潮期不抄概念底，等资金回流先看执行器/丝杠、再看设备卡口的补涨。
