## 三、产业链结构图与关键环节分析

```text
人形机器人产业链（执行器主线）
├─ 下游：整机厂（Tesla/宇树/智元/海内外）
├─ 执行器总成（旋转/直线执行器）
│   ├─ 行星滚柱丝杠（线性执行器核心）
│   ├─ 谐波/行星减速器（旋转执行器）
│   ├─ 无框力矩电机 / 编码器 / 制动器
│   └─ 传感器（力矩/视觉/触觉）
├─ 丝杠上游
│   ├─ 特种钢材 / 热处理
│   └─ 螺纹磨床（高精度螺纹磨削设备）★卡口
└─ 设备耗材
    └─ 超硬磨料砂轮（CBN/金刚石）★本周资金最猛
```

**关键环节分析**：整机与执行器总成已多家布局、扩产快、壁垒中等；丝杠本身是工艺瓶颈（精度/寿命/一致性）；但最硬的物理约束在**上游高精度螺纹磨床**——将丝杠螺纹磨到微米级精度，长期被瑞士斯图特(Studer)、德国赖斯豪尔(Reishauer)等垄断，国产刚起步。磨床又依赖**超硬磨料砂轮（CBN/金刚石）**，本周黄河旋风等被资金集中抢筹正是这条逻辑的外溢。

## 四、瓶颈/卡口环节判断（断点分析）

1. **谁是寡头/唯一**：高精度螺纹磨床全球寡头（瑞/德系），国内秦川机床、华辰装备等在突破但未放量；丝杠用 CBN 砂轮由少数超硬材料厂掌握。
2. **扩产要多久**：高端磨床从研制到稳定量产 + 客户认证 2–3 年；超硬砂轮扩产快于设备但高端品仍受限。
3. **有没有替代**：丝杠螺纹必须靠高精度磨削，无替代工艺；砂轮规格绑定设备，黏性强。
4. **下游必须用**：人形机器人量产放量，丝杠与磨床为刚性产能瓶颈，缺一不可。

叠加卡口四条件，**最紧缺环节 = 行星滚柱丝杠上游的"高精度螺纹磨床"（设备卡口）+ 行星滚柱丝杠制造本身（工艺卡口）**；超硬磨料砂轮（CBN/金刚石）为磨床上游耗材卡口，本周已被资金率先定价。

> 注：本链主路线与平台既定跟踪重点（行星滚柱丝杠及上游螺纹磨床）一致，本周盘面与研判互相印证。

## 五、预期差与投资机会提示

- **预期差**：市场常聚焦整机与丝杠成品（已较热），但"卖设备给丝杠厂"的磨床与"卖砂轮给磨床"的超硬材料，是更上游、更寡头、预期差更大的环节。
- **跟踪线索**：① 秦川机床、华辰装备等螺纹磨床订单与交付；② 黄河旋风/惠丰钻石/沃尔德 CBN 砂轮在丝杠领域的客户突破；③ Tesla/国内整机厂量产节奏对丝杠产能的拉爆。
- **节奏提示**：黄河旋风单日 +12.3 亿净流入属极端值，警惕短线情绪过热，中线以磨床/砂轮国产替代兑现度为准。
