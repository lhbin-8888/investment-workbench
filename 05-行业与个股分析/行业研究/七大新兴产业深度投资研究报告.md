## 2. 人工智能产业

### 2.1 产业现状与市场规模

- 中国AI核心产业规模：2024年约7330亿元，2025年约9481亿元，2026年预测1.25万亿元（中商产业研究院）。
- 中国AI大模型市场：2025年495.39亿元（同比+49.1%），2026年破700亿元，2030年剑指3250亿元。
- 全球AI市场：2026年破5000亿美元，2024-2028年CAGR 32.1%（IDC）。
- 中国AI企业超4800家；智能算力总规模188万PFLOPS（FP16，2026年3月底数据）。

### 2.2 发展前景

- 大模型从"参数竞赛"转向"应用与Agent落地"，推理算力需求进入爆发期（推理算力远期约为训练的8倍）。
- 开源模型推动全球算力平权，DeepSeek、阿里通义等开源生态重塑竞争格局。
- 智能体（Agent）为2026年最确定的商业化方向，C端消费+B端行业（办公/政务/工业/医疗/金融/教育）同步渗透。

### 2.3 核心环节与核心技术

三层架构：

| 层级 | 环节 | 核心技术 |
|---|---|---|
| 基础层（利润最高/壁垒最强，占全链60%+毛利） | AI芯片、服务器/智算中心、HBM存储、IDC液冷、数据服务 | GPU/NPU/ASIC、先进封装、液冷散热、高质量数据集 |
| 技术层 | 深度学习框架、大模型、Agent平台 | LLM/多模态/长上下文、PyTorch/TensorFlow/昇思/飞桨、智能体编排 |
| 应用层 | C端消费+B端行业应用 | RAG、工作流自动化、行业垂直模型 |

### 2.5 未来领军企业预判

- **算力国产替代主线**：华为昇腾（政策+集群+生态）、寒武纪（纯自研ASIC）、海光信息（CUDA兼容迁移成本低）。
- **推理算力爆发**：智算中心Token工厂、液冷IDC相关龙头。
- **Agent赛道（2026最确定）**：智能体平台/多智能体企业（如智谱GLM等）。
- **开源模型主导者**：DeepSeek、阿里通义千问（全球算力平权受益者）。

### 2.6 风险提示

- 一级/二级市场估值泡沫（部分标的PE畸高，如摩尔线程PE 2392倍）。
- 商业化落地不及预期；大模型同质化竞争加剧。
- 地缘政治导致高端算力供给受限、出口管制反复。

## 3. 人形机器人产业

### 3.1 产业现状与市场规模

- 2025年全球人形机器人市场规模约170亿元，中国85亿元（占全球50%+）；2025年全球出货量约1.7-1.86万台，中国占84.7%-90%。
- 2026年（量产元年）中国市场规模预计突破220亿元（同比+138%），全年整机产量有望突破10万台（工信部）。
- 长期空间：2030年中国市场约8700亿元（中国电子学会）；IDC预测2029年全球206亿美元；2045-2050年全球或破7.6万亿美元。
- 政策：纳入"十五五"六大未来产业；工信部+国资委开展"2026年度人形机器人与具身智能实景实训专项行动"，目标年底万台级落地。

### 3.2 发展前景

- 应用路径：短期工业（汽车/3C/巡检）→ 中期物流/商用服务 → 长期家庭/养老。
- 竞争核心从硬件转向"具身智能大模型"：VLA（视觉-语言-动作）→ 世界模型（WAM）→"快慢系统/大小脑"架构；仿真+真机混合训练成范式。
- 核心零部件占整机成本70%-85%，价值集中、壁垒最高，国产替代空间大。

|---|---|---|
| 执行器总成 | 线性/旋转执行器，关节模组 | 38-42% |
| 控制器 | 运动控制、大小脑算法 | 15-18% |
| 传感器 | 六维力（手腕/脚踝）、3D视觉、触觉、IMU | 约16.8%（六维力占11.2%） |
| 减速器 | 谐波（轻载）、RV（重载） | 12-15% |
| 电机 | 无框力矩电机（大关节）、空心杯电机（灵巧手） | 10-12% |
| 丝杠 | 行星滚柱丝杠（线性执行器最贵卡点） | 核心卡点 |
| 灵巧手 | 自由度20+、触觉反馈 | 约14% |

- 产能过剩风险；客户集中（特斯拉链依赖）；高端丝杠/IMU仍依赖进口。

## 4. 航空航天产业

### 4.1 产业现状与市场规模

- 商业航天：2025年中国市场规模2.83万亿元（同比+21.7%），2026年预计3.5万亿元；2026年政府工作报告首次将商业航天定位为"新兴支柱产业"（与集成电路、生物医药并列）。
- 卫星互联网：2025年国内核心市场约454亿元，2026年约471-500亿元，2026-2030年复合增速约30-32%；2030年核心市场有望破5000亿元、关联产业超1.3万亿元。
- 大飞机C919：累计订单突破1500架（确认有效订单超1150架），累计交付超42架，开通57条航线、载客超800万人次；2026年8月开通首条常态化国际航线（北京-乌兰巴托）。
- 航空发动机：2025年中国航发行业市场559.67亿元（民用占59.82%）；未来20年新机+维修市场超4万亿元，其中商用航发超2.9万亿元。

### 4.2 发展前景

- 低轨星座组网进入加速期（千帆/星网），可回收火箭推动发射成本从10万美元/kg降至<1万美元/kg，打开规模化组网经济性空间。
- C919产能爬坡（2028年规划年产150架、2029年冲击200架）+ C909/C929机型矩阵成型，产业链进入业绩兑现期。
- CJ-1000A国产发动机2027年取证预期，航发自主可控链条价值重估。

### 4.3 核心环节与核心技术

**A. 商业航天/卫星互联网（三层架构）**

- 上游（制造+发射，壁垒最高）：卫星制造、火箭发射（可回收液氧甲烷发动机）、星载相控阵T/R芯片、宇航电源、恒星敏感器、激光星间链路。

## 7. 电力产业

## 8. 有色金属产业

### 8.1 产业现状与市场规模
