## 三、产业链焦点（断点分析 · 来自 chanyelian-duandian）

> 方法：画链 → 锚定龙头 → 下钻物理瓶颈 → 卡口四条件 → 辨短缺性质 → 验定价 → 风控 → 事件三问。结论只对物理约束负责，不追概念。

**1) 画链（下游应用 → 大模型 → 算力集群 → 硬件 → 上游）**
- 下游应用：大模型应用（科大讯飞等）、互联网大厂/运营商/政务的 AI 推理与生成式服务。
- 中游模型层：基座大模型训练与推理（算力消耗总源头）。
- 算力集群层：AI 服务器（工业富联、中科曙光）、智算中心、液冷基础设施。
- 硬件核心层：
  - 算力芯片：AI GPU/ASIC（寒武纪、海光 DCU）；
  - 光互连：高速光模块（中际旭创、新易盛）+ **上游光芯片（EML/硅光/DSP）**；
  - 载板互联：高端 PCB（沪电股份）、IC 载板、连接器；
  - 存储：**HBM 高带宽内存**；
  - 封装：**先进封装 CoWoS**；
  - 散热供电：液冷、电源。

**2) 锚定龙头（需求端入口）**
需求总开关是"大模型训练/推理的算力军备竞赛"——北美云厂商（微软/谷歌/Meta/亚马逊）+ 国内大厂（字节/阿里/腾讯）+ 运营商智算中心。全球锚为英伟达，国内映射为寒武纪（国产算力芯片）、工业富联（服务器代工）、中际旭创（光模块全球份额）。龙头只是入口，沿"应用 → 算力集群 → 芯片/光互连/存储/封装 → 最上游材料与设备"逐层上钻，才能找到被产业爆发最先挤爆的环节。

**3) 下钻物理瓶颈（物理四问逐层验）**
- **算力芯片（寒武纪/海光）**：① 寡头？训练级 GPU 全球英伟达寡头，国产（寒武纪/海光）处于替代爬坡。② 扩产多久？受**先进制程产能**（台积电/中芯国际）与 **CoWoS 先进封装**硬约束，短期扩不出。③ 有无替代？国产算力是必选项（地缘约束下不可替代）。④ 下游必须用？是。→ 受"先进制程 + 先进封装"双卡。
- **光模块（中际旭创/新易盛）**：全球份额高（中国光模块占全球 70%+），但**整机扩产较快**（非最硬物理瓶颈），且机构认知充分、**已充分定价**；真正瓶颈在其**上游光芯片**。
- **上游光芯片（高速 EML / 硅光 / 相干 DSP）**：① 不可替代？1.6T 光模块必须配高端 EML/硅光与 DSP。② 供给刚性？化合物半导体产线（磷化铟/砷化镓）扩产慢、良率爬坡难。③ 寡头垄断？高端 200G+ EML、1.6T DSP 由博通/思科/三菱/住友等海外寡头主导。④ 无人看见？市场焦点在整机厂（中际/新易盛），**上游芯片国产薄弱长期被忽视**——预期差最大。
- **HBM 高带宽内存**：① 不可替代（GPU 必配）。② 供给刚性（TSV 硅通孔先进工艺，扩产 18–24 个月）。③ 寡头（SK 海力士/三星/美光）。④ 无人看见？❌ 机构已高度共识其为 AI 瓶颈，**已充分定价**（体现在英伟达链整体估值中）。
- **先进封装 CoWoS（台积电）**：AI 芯片产能"卡口中的卡口"，台积电寡头、扩产慢、不可替代；但同样**已被市场共识定价、A股纯标的稀缺**，超额有限。
- **高端 PCB（沪电）/ 液冷 / 电源 / 服务器代工（工业富联）**：供应成熟、扩产中等，非最硬物理瓶颈；PCB 本周领跌，预期正在松动。

**5) 辨短缺性质**
- **上游光芯片**属**长期结构性短缺**：化合物半导体材料/工艺的物理硬约束 + 海外寡头专利壁垒，短期无法突破 → 对应长期趋势行情，非一日游。
- **算力芯片先进制程/CoWoS 国产约束**属**长期结构性 + 地缘政治双约束**，短期无解，是国产算力放量的真瓶颈。
- **HBM / CoWoS（全球侧）**虽是物理最硬瓶颈，但属"已共识、已定价"的公开卡口，按本方法不追（超额已交易在英伟达链股价里）。

**6) 验定价（故事 vs 产业事实）**
- 产业事实支撑：北美云厂 Capex 继续上修、1.6T 光模块放量、国产算力（华为昇腾/寒武纪/海光）出货爬坡、智算中心集采加速。
- 估值已高需真放量验证：寒武纪 205×、海光 181×、科大讯飞 108× 明显偏高；中际旭创 47×、新易盛 42×、沪电 43×、工业富联 27× 相对克制（反映"量价齐升"但预期更理性）。**盘面信号**：本周光模块代表股（中际 −4.45%、新易盛 −3.95%）与 PCB（沪电 −10.74%）同步跑输，提示"量价齐升"高位叙事开始分化，需出货量/价格兑现才能打开上行。

**7) 风控**
不重仓单一赛道、单一标的；接受单标的 20%–30% 最大回撤，换取下行有限、上行放开的赔率。本赛道估值分位偏高、且本周板块相对强度转弱（超额 −2.94pct），回撤纪律优先于追涨。

**8) 事件三问（遇大额订单/中标/政策催化时套用）**
- 订单落地需配套：HBM + CoWoS 封装 + 光模块 + **上游光芯片**，缺一不可。
- 率先扛不住的瓶颈：台积电 CoWoS 产能 + 高速光芯片供给（1.6T 时代最先断供的节点）。
- 竞争对手被卡点：先进制程获取与光芯片 know-how（非资本即可速成）。

**★ 产业链焦点定性结论**：真卡口 = **上游高速光芯片（EML/硅光/DSP）国产替代**——这是全球 AI 链中"国内最薄弱、最未被充分定价"的环节（整机厂已充分定价，上游芯片预期差最大）；次真卡口 = **国产算力芯片的先进制程 + CoWoS 封装产能约束**（地缘+产能双约束，长期结构性短缺）。已充分定价的共识卡口（HBM、CoWoS 全球侧）与已定价跳过环节（光模块整机、PCB、液冷、服务器代工）不追。资金后续最安全超额，落在"光芯片国产替代 0→1"与"国产算力产能突破"这两个最上游、最硬、最未被充分定价的物理瓶颈上。
