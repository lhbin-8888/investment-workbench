## 二、资金面动向

- **硬件 > 软件**：电子（+90.90 亿）、半导体（+77.35 亿）占据行业资金前二，计算机、软件虽涨但绝对流入量级小一个档位，符合"算力紧缺→硬件先受益"的产业传导。
- **存储成为新焦点**：存储芯片概念净流入 48.27 亿，长鑫科技、兆易创新、普冉股份（+3.41 亿）、东芯股份（+1.87 亿）同步走强，HBM/DRAM 国产链被资金系统性买入。
- **PCB 出现分歧**：印制电路板净流入 6.52 亿，但结构为"超大单 +13.10 亿、大单 -6.57 亿"，元件同样"超大单 +11.53 亿、大单 -7.32 亿"——**大资金进场、中小资金派发**，是典型的高位分歧信号。
- **涨停池**：全市场 50 家涨停中，半导体 3 家、IT 服务 3 家、计算机设备 2 家、软件开发 2 家；博通集成 3 连板（半导体，封单 1.24 亿）。
- **结论**：AI 仍是资金最拥挤的主线，但内部分歧加大，资金从"整板普涨"走向"环节精选"。

## 三、产业链结构图与关键环节分析

```
上游（卡口区）   算力芯片(GPU/ASIC) / HBM / 先进封装(CoWoS) / 高端PCB·IC载板 / 光模块 / 液冷 / 电源
      ↓
中游             大模型训练 / 云服务 / 推理部署 / 服务器整机
      ↓
下游             办公 / 编程 / 搜索 / 行业应用等场景
```

### 3.1 断点分析路径（八步）

1. **画链**：按上游算力硬件—中游模型与云—下游应用三层画全。
2. **锚定需求端龙头**：海外以英伟达、微软、谷歌的资本开支为总需求源；A 股入口为海光信息、寒武纪、阿里云与服务器整机厂。
3. **逐层下钻**：算力需求 → GPU/ASIC → HBM → 先进封装（CoWoS）→ IC 载板 / 高频高速 PCB → 覆铜板（CCL）→ 电子布与特种树脂。
4. **物理四问**：见下表。
5. **卡口四条件**：逐环节打分。
6. **辨短缺性质**：HBM 与 CoWoS 的全球性短缺属长期结构性（产能受物理厂房与设备限制）。
7. **验定价**：用今日资金与涨幅验证。
8. **风控**：板块拥挤度极高，单标的可承受 20%–30% 回撤，不重仓追高。

### 3.2 逐层下钻与物理四问

| 下钻层级 | 代表环节 | 谁是寡头/唯一 | 扩产要多久 | 可否替代 | 下游必用 | 判定 |
| --- | --- | --- | --- | --- | --- | --- |
| 第一层 | 大模型应用 | 分散 | 短 | 可替代 | 否 | 非卡口 |
| 第二层 | 光模块 800G/1.6T | 中国厂商领先 | 1 年 | 部分可替代 | 是 | 已充分定价 |
| 第三层 | 高端 PCB / IC 载板 | 台系领先，大陆追赶 | 1.5–2 年 | 认证壁垒高，不可轻换 | 是 | **真卡口（A股可投）** |
| 第四层 | 先进封装 CoWoS | 台积电主导 | 2–3 年 | 不可替代 | 是 | 全球卡口（A股为供应链） |
| 第五层 | HBM / DRAM | 三星、SK 海力士、美光寡头 | 2–3 年 | 不可替代 | 是 | **卡口（国产替代空间大）** |
| 第六层 | 电子布 / 特种树脂 | 日系主导 | 1–1.5 年 | 部分可替代 | 是 | 准卡口 |

**物理四问的核心答案**：HBM 的物理约束在于**堆叠层数与 TSV 通孔密度**，CoWoS 的约束在于**台积电封装产能与厂房**，二者扩产均需 2 年以上；高端 PCB/IC 载板的约束在于**良率与客户端认证**，扩产快但认证慢，因此供给弹性和需求刚性同时成立。

## 四、瓶颈 / 卡口环节判断

| 环节 | 不可替代 | 供给刚性 | 寡头垄断 | 无人看见 | 判定 |
| --- | --- | --- | --- | --- | --- |
| 高端 PCB / IC 载板 | 是 | 是（认证+产能） | 中（台系领先） | 部分 | **真卡口（A股可投）** |
| HBM / 存储国产链 | 是 | 是（长鑫等产能爬坡） | 部分 | 部分 | **真卡口（国产替代）** |
| 先进封装 CoWoS | 是 | 是 | 是（台积电） | 否（已定价） | 全球卡口 |
| 光模块 | 中 | 中 | 中 | 否 | 已充分定价 |
| 液冷 / 电源 | 否 | 否 | 否 | 否 | 非卡口 |

**短缺性质判断**：**长期结构性短缺**。HBM 与 CoWoS 属全球物理产能瓶颈；国产侧，存储在长鑫/长存产能爬坡完成前，国产 DRAM/HBM 供不应求具长期性。

**定价验证**：本周资金明确验证"存储 + 数字芯片设计"这一组合（存储芯片 +48.27 亿、数字芯片设计 +71.66 亿）。而 PCB/元件出现"超大单进、大单出"的方向分歧，说明该环节定价已较为充分、进入博弈阶段。上游载板/CCL 与存储国产链仍有预期差。

**最紧缺环节结论**：AI 算力硬件"卖水人"——**存储（HBM/DRAM 国产链）与高端 PCB / IC 载板并列**，本周资金重心偏向存储。

## 五、预期差与投资机会提示

1. **存储国产链确定性最强**：长鑫、长存扩产带来的设备、材料、封测配套是本周资金最集中方向，关注产能爬坡与国产替代率提升。
2. **载板 / CCL 扩产兑现**：关注高端产能投产、通过大客户认证的 PCB/载板与覆铜板厂，认证周期决定稀缺性。
3. **先进封装材料与设备**：国产 CoWoS 配套（封测、封装基板、键合设备）是确定性次主线。
4. **节奏提示**：PCB/元件出现超大单与大单背离，追高性价比下降；存储与芯片设计资金合力更强，但连续上涨后需防分歧回踩。

## 六、风险提示

- 海外算力芯片出口管制再升级，冲击国产算力供应链；
- 全球 AI 资本开支不及预期或云厂商削减订单；
- HBM/存储价格周期回落，涨价逻辑反转；
- PCB/光模块产能过剩与价格战；
- 板块资金拥挤度极高，大单已现派发迹象，回撤弹性大；
- 本报告为盘中数据快照，午后及收盘数据可能显著偏离。
