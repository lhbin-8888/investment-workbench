# 个股深度

## 用途
存放个股深度研究报告，包括商业模式、护城河、成长性、管理层等全面分析。

## 推荐文件命名规范
```
股票代码_股票简称_YYYYMMDD_深度报告.md
```
- 示例：`600519_贵州茅台_20260731_深度报告.md`

## 建议内容要素
- 公司概况（主营业务、实际控制人、上市时间）
- 商业模式与护城河
- 财务分析摘要（近3-5年核心指标）
- 成长逻辑与催化剂
- 风险提示
- 估值与目标价
