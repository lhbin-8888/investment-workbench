## 四、没生效 / 新暴露的问题

### P0-1　"破 10 日线"接管出口，仍砍在开盘第一分钟
出场结构（35 笔）：**破均线清仓 21 笔（60%）**、分批止盈 6 笔（17%）、移动止盈 4 笔（11%）、ATR 止损 4 笔（11%）。

出场时刻：**09:31 共 13 笔**，09:32/09:33/09:35 各 1 笔 → **09:35 前 16 笔（46%）**；而 **14:48 及以后 0 笔**。

4 笔 ATR 止损**全部发生在 09:31**（浮亏 −9.2% ~ −9.8%）。

**根因**：`RETREAT_MA=10` 与 ATR 止损用的是 **T-1 日 K**，在 09:31 就能判定成立，于是立刻市价卖出；而板块级清仓被时间闸门锁在 14:48 —— **顺序上永远抢不过**。V4.5 把"板块清仓"挪出开盘，但真正干活的换成了"破均线"，问题只是换了个名字。

### P0-2　毛利≈0，成本吃掉全部
区间成交额约 **72.6 万元**（买入 36.3 万 × 双边近似），平均总资产 9.82 万 → 区间双边换手 **7.4 次**。
- 区间成本 ≈ **2.5% 权益**；折年 ≈ **17.4% 权益**
- 区间收益 −2.6% + 成本 2.5% ⇒ **毛利 ≈ 0**

**这是和 V4 完全相同的结论**。年换手 50 次对应 17% 的年成本，A 股热点轮动策略的毛利很难长期覆盖这个数。**不把换手压到 20~25 次/年，调别的参数都是白费。**

### P1-3　分批止盈存在逻辑 bug + 每分钟刷屏
`热点早盘001_V4.5.py` L1937：
```python
if 0 < half < amount and tr_half >= half:
```
当日志出现 **`可卖100股/需100股`** 却走 else 分支时，说明 `half == amount`（持仓仅 1 手，减半取整后仍等于全部持仓）→ `half < amount` 不成立。
实测 2026-05-20 11:21~11:30 **连续 10 次**报"可卖量不足（100股/需100股）"，浮盈 12.4%~13.5%：
- 该盈利单**始终没能减仓**；
- 因未写入 `g.partial_done`，**每分钟重复判定**，白刷日志。

**修法**：`if 0 < half <= amount and tr_half >= half:`，并在"减半后等于全仓"时直接按一次性止盈处理或写入 `partial_done` 停止重判。

### P1-4　22.5% 的候选买不到（逆向选择）
9 笔委托被拒：`688380 688655 688549 600508 603979 000636 002335 300747 301366`，全部为 `Order Rejected: can not match. Market close.`
限价 = 假设价 × 1.005 ≈ T-1 收盘 × 1.015，**次日跳空高开超过 1.5% 且不回补的票一律买不到** —— 而这批恰恰是最强的票。**买到的样本被反向筛选成"次日没高开"的那批**，与 V4 的 30.6% 拒单同源，只是比例略降。

### P1-5　仓位利用率只有 40%
平均日初持仓 **3.41 只**（上限 6），持仓分布 `{0:3, 1:4, 2:3, 3:9, 4:6, 5:12, 6:2}`；成交建仓中启动期 11 笔（15%）、扩散期 19 笔（10%）→ **平均单票占比 11.83%，平均仓位 ≈ 40.4%**。

三重压制叠加：① 每日新建仓上限 2 笔（日志触发 10 次"已达每日新建仓上限"）；② 扩散期半仓只给 10%；③ 候选不足（2 天入选 0 只）。
**代价**：用 40% 的仓位承担了 7.48% 的回撤，风险收益比很差。

### P2-6　日志 52% 是重复噪声
`破10日线但持仓仅N日(<3日)，暂不噪声止损` 一条 **2627 次**，占全部 5055 条日志的 **52.0%**；单只票最高刷 482 次（301282 / 300383 / 002449）。
建议：把该提示改为**每日每票只打一次**（用 `g.logged_today` 集合去重），或降到 DEBUG。

## 五、收益反推方法与可信度

日志**没有输出现金/净值/绩效**（`回测统计数据汇总完成` 只打了一行字，无数字）。收益是从 `[买入]` 行的**目标金额**反推的：

```
目标金额 = 总资产 × 单票比例
启动期 比例 0.15 ；扩散期 比例 0.10
→ 总资产 ≈ 目标金额 ÷ 比例
```

反推结果（逐建仓日）：

| 日期 | 总资产 | 日变动 |
|---|---|---|
| 05-06 | 100,000 | 起点 |
| 05-11 | 102,520 | 最高点 +2.5% |
| 05-18 | 98,848 | |
| 06-01 | 96,000 | |
| 06-15 | 94,850 | **谷底 −7.48%** |
| 06-18 | 96,940 | |
| 06-24 | 97,400 | 最后建仓日 |

**可信度**：
- 在 V4 上校准：反推 −0.24% vs 面板 +2.05%，**偏差约 +2pp（低估）**，源于反推截止到"最后建仓日"，而面板按期末收盘计价。
- 因此 **V4.5 真实区间收益大概率在 −2.6% ~ −0.3% 之间**。
- 反推用的是"目标金额"，受整手取整与流动性截断影响，单点误差 ±0.5pp。
- **结论需要面板截图最终确认**（策略收益 / 年化 / 最大回撤 / 夏普 / 基准收益）。

## 六、建议动作

### P0（决定策略生死，必须先做）
1. **给"破均线清仓"和"ATR 止损"加统一时间闸门**：改为 **14:45 后判定**，或改用**收盘价确认跌破**（而非盘中触及）。这是当前 60% 出场、46% 开盘 5 分钟内成交的直接来源。
2. **把年换手压到 20~25 次**：这是"毛利≈0 + 成本 17%"的唯一解药。手段：延长最短持有、提高移动止盈武装线、减少同时持仓数、或干脆降低交易频率到"周频"。
3. **拿到面板绩效数据**，确认收益/回撤/夏普/基准的真实读数。

### P1（低成本、见效直接）
4. 修 `half <= amount` 的 off-by-one，并给 `partial_done` 补上"减半等于全仓"的情形。

6. 提高仓位利用率：每日新建仓上限 2 → 3 笔；扩散期单票 10% → 12~13%。目标是平均仓位 55~65%。

### P2（清洁度）
