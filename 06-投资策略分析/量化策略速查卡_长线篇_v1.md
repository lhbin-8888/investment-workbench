## 总纲三条铁律（先记住）
1. **量化策略不是输在选股，是输在出场与成本。**（长线股 §一）风控与成本纪律放收益预期之前；T 是降本练兵不是提款机，核心仓位一根毛都不能被做丢。
2. **先证瓶颈再改参。** 改了 N 版出场收益不动，先算"买入后什么都不做 vs 基准"的超额，确认是选股还是出场问题再动手（长线股 §七）。
3. **无未来函数。** 全链路只用已收盘数据，实时价仅作建仓护栏。

## 一、标的与三层资金架构
> 来源：长线股三层量化设计（v1.5~v2.0）

- **标的来源**：从自选股筛"长期质量"（护城河、产业景气、财务健康、估值合理）。示例 16 只组合。
- **三层资金架构（骨架）**：
  | 层 | 占比 | 职责 | 纪律 |
  |---|---|---|---|
  | **L1 长线底仓 Core** | 58% | 长期持有捕获复利 | 不可被 T/波段做丢；季度再平衡；单票 ≤8%；行业上限封顶（半导体≤25%/资源≤30%/消费≤25%/医药≤20%）；只在基本面破坏时剔除 |
  | **L2 波段卫星 Swing** | 25% | 优质票回调做价差 | 独立资金池，只在高流动性子集做 |
  | **L3 现金 + T 机动** | 17% | 缓冲 + T 周转 + 极端补仓 | — |
- **关键隔离**：L1 是"不动的锚"，Swing/T 只能在 L1 之上做"卖出后必须同日/次日买回"的闭环。

## 二、估值选尺（选标的 + 定贵贱）
> 来源：个股估值技能

- **先判类型选主尺**：
  | 公司类型 | 主估值尺 |
  |---|---|
  | 成熟盈利蓝筹 | PE + DCF |
  | 稳定成长 | PEG |
  | 亏损高成长 | PS |
  | 强周期 | PS + PB |
  | 重资产金融 | PB + 股息率 |
  | 无形资产（品牌/平台） | PB 会失真，跌破 1 反而是机会 |
- **两把尺交叉验证**；结论永远是**区间不是点位**——悲观情景重算 = 安全底线。
- **安全边际**：股价远低于悲观情景下限才有厚垫；永续增长率守 1%–3%（别超过长期 GDP 增速）。

## 三、买入条件（长线）
> 来源：长线股 L2 波段买点 + 热点策略通用护栏（复用）

### 3.1 L2 波段买点（四条件同时）
- 价格回落至 20/60 日线附近（偏离 ≤-3%）；
- 量比 <0.8（地量，非恐慌抛售）；
- RSI(14) ∈ [35,55]（非超卖恐慌、非过热）；
- 大环境非单边下行（宽基在 60 日线上方，详见 §四市场开关）。

### 3.2 L3 日内 T 触发（纯降本）
- 当日振幅 >1.5% 且出现明确日内摆动才做；
- 单次动用 ≤ 持仓 20%；单日单票 ≤1–2 回合；
- 卖出的份额必须当日（最迟次日）买回；
- 单回合预期价差 <0.4% 不做（覆盖不了冲击成本就是送钱）。

### 3.3 通用护栏（复用热点策略）
- 不追涨停、不追一字板；涨幅按板块分档收窄上限降追高。
- 双护栏：走弱不接刀、涨过头不追；高开 >2% 放弃。
- 必须站上 MA20（`REQUIRE_ABOVE_MA20`）；量比 <0.8 才算地量买点。

## 四、止盈止损（长线）
> 来源：长线股 L2 + 组合断路器 + V1.9 市场开关

- **L2 波段卖点（任一即出）**：
  - 目标 +12%~18%；
  - RSI>70 或触 20 日布林上轨；
  - **硬止损 -7%**；
  - 自最高点回撤 ≥8%。
- **ATR 动态止损**（长线股 + 热点策略通用）：成本 -1.8×ATR 清仓；下限 5%/上限 8% 防隔夜跳空瞬时刺穿。
- **时间止损（长线股 `STALE`）**：横盘 ≥8 日且收益落在成本 ±1.5% 窄带 → 主动退出释放资金。
- **破线出场**：破 EXIT_MA(3 日) 快出；破 RETREAT_MA(20 日) 退潮清仓。
- **⚠️ 组合级断路器（最重要，长线股）**：组合自高点回撤
  - **-8%** → 暂停所有 L2/L3，仅持 L1；
  - **-12%** → 砍 1/3 高位/高估值 L1；
  - **-18%** → L1 再减半进入防守。
- **市场开关（大环境总闸，V1.9 实测降档半仓把亏损压到一半）**：
  - 沪深300/中证800 在 **60 日线下方** → L2 降为 0；
  - **120 日线下方** → 额外砍 L1 20%、现金升至 30%+。

## 五、仓位与资金管理
- **三层架构隔离**：L1 不动如山、L2 机动、L3 现金 T；核心仓位一根毛都不能被做丢。
- **成本预算锁手痒**：A 股单回合成本 ≈ 佣金 0.025%×2 + 印花税 0.05%(卖) + 过户费 ≈ **0.10%~0.13%**；年度成本预算 ≤1.5% → 全组合约 **7 回合/年**额度，倒逼只做高确定性信号（任何新信号先证 edge > 成本 ×3）。
- **资金规模要匹配标的池（实测教训）**：同版本同区间 **30 万 +0.15% vs 10 万 -4.97%**，差异不在参数、在整手粒度导致小资金分散化失效、权重畸变——小资金别硬套大盘蓝筹池。

## 六、PTrade 工程纪律（长线相关）
> 来源：长线股设计 §六 + 热点策略 v3 启动自检

- **托管机房约束**：Python 3.5、无外网、无 os、无高级库；所需数据（行业映射、估值参数等）必须随策略文件带上去。
- **口径坑（猜错 = 静默错）**：`volume` 单位是**股不是手**；代码后缀 `.SS/.SZ/.BJ`；持仓 `enable_amount`=可卖量(T+1)、`current_amount`=总持仓，当日新仓只能看后者；涨跌停按板区分（主 10%/双创 20%/北交所 30%/ST 5%）。
- **回测当日价**：只能走 `data` 参数或分钟线，直接读 `close[-1]` 拿到的是昨收；成交量单位启动自动校准。
- **成本模型必须含印花税(卖出 0.05%) + 双边佣金**；滑点建议单边 0.1%~0.15%。
- **上线三步走**：默认 `TRADE_ENABLED=False` → 先跑信号模式 3–5 日核对日志 → 模拟盘 → 小资金实盘。
- **L1 不可被做丢的护栏**：T/波段卖出份额必须同日或次日买回，任何路径都不得让 L1 底仓净减少（除非基本面破坏剔除）。
- **版本管理（按老规矩）**：每优化一版生成新文件带版本号，旧版保留可回退；先小步验证、保留原版参数复现做归因基线。

## 七、可照抄的操作节奏（长线）
- **盘前**：看宽基 60/120 日线定市场开关（L2 是否降档/禁开）；查持仓组合回撤 vs 断路器阈值。
- **开盘（09:30）**：L3 日内 T 只在振幅 >1.5% 且出现明确摆动时做，单日单票 ≤1–2 回合。
- **盘中**：L2 买点达"四条件"才触发；每分钟 + 14:58 风控巡检（ATR 止损 / 破线 / 组合回撤 vs -8%/-12%/-18%）。
- **收盘（15:05）**：打印盈亏台账（胜率 / 回撤 / 最大回撤 / 成本消耗）。
- **季**：L1 季度再平衡（单票 ≤8%、行业上限封顶）；成本预算消耗核对（是否超 7 回合/年）。
