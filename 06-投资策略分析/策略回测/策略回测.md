# 策略回测功能模板

> 所属模块：06-投资策略分析
> 核心目标：以可复现的回测数据验证策略有效性，形成「策略—参数—结论」闭环

## 一、模块定位说明

本模块用于记录量化 / 交易策略的回测代码、回测结果与参数优化记录。策略回测是把交易想法变成可验证结论的关键环节，通过统一指标口径避免「凭感觉选策略」，并为实盘上线提供依据。

适用场景：新策略开发验证、既有策略参数调优、策略失效归因、实盘上线前的复现核对。

## 二、数据来源建议

| 数据类别 | 推荐来源 | 说明 |
| --- | --- | --- |
| 行情数据 | PTrade / 券商行情、东方财富 | 日线或分钟线 |
| 交易成本 | 佣金 + 印花税 + 滑点模型 | 见 `ptrade_verify/cost_model.py` |
| 板块成分 | 东方财富板块池（`sector_map.json`） | 用于热点型策略选股 |
| 基准指数 | 沪深300 / 中证500 / 创业板指 | 计算超额收益 |
