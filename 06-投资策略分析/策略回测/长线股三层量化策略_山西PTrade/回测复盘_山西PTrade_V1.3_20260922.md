## 三、根因：结构性单向失血（D22）

### 3.1 减仓 / 回补 次数严重不对称

| 动作 | 笔数 | 触发机制 |
|---|---|---|
| 市场开关 L1 减仓 | 13 | **事件驱动**（跌破 120 日线即砍一档）|
| L1 止盈减仓 | 5 | **事件驱动**（浮盈 ≥15% 即砍）|
| L1 再平衡减仓 | 2 | 日历驱动（每 60 日）|
| **减仓合计** | **20** | 随时可能发生 |
| **L1 建仓 / 回补** | **12** | 日历驱动（仅首月 + 每 60 日季度再平衡）|

**同一层里，减仓是「事件驱动、高频」，加仓是「日历驱动、低频」。**

### 3.3 机制层面的证据

市场开关全期触发 **86 次**：`暂停新开 68 次` / `恢复复位 12 次`。其中「L1 档位复位」7 次（03-06、03-11、04-13、07-15、08-18……），日志原文是：

```
[市场开关] 沪深300 回到120日线上方(连续1日) -> L1 档位复位，再次跌破可再减仓
```

**「档位复位」只清零计数器，让下次跌破可以再砍——它不回补仓位。**

所以完整链条是：**跌破 → 砍一档（13 次）→ 回到上方 → 只复位、不买回 → 再跌破 → 再砍……** 仓位单向流失。

### 3.4 代价

5–6 月减仓确实避开了下跌（保护有效，-7.36% 回撤 vs 基准 -0.16% 年化），**但 7–8 月指数回升时仓位仍是 32%，反弹只吃到三分之一**。若回补对称，7–8 月的涨幅按仓位比例可放大约 1.8 倍。

## 四、另两条结构性缺陷

### D23【P0】L2 卫星层完全无法落地

- 8 个月触发买入信号 **5 次**：`688072.SS`、`688012.SS`、`688111.SS`×3 —— **全部是科创板高价股**。
- 单票预算 7,500 元，而这些票 1 手成本：688072 = 330.00×200 = 66,033 元；688111 = 307.07×200 = 61,445 元；688012 = 272.72×200 = 54,571 元。
- 实测：**订单汇总里 0 笔 688 系列成交**，`L2回合 = 0`。
- 更严重的是——**信号被静默丢弃，没有 `[买不起]` 告警**（该告警只覆盖 L1 路径）。

启动日志其实已经预警过：

```
[资本适配] L2 等权单票预算7500 元 -> 可建仓 4/10 只；按单只上限30000 元动态分摊 -> 可覆盖 6/10 只 | 名义25.0%
```

但 L2 的信号源（MA20 / 量比 / RSI 三条件）偏好的是**超跌的高价科技股**，与「买得起」完全不交集。

### D24【P1】L3 日内 T 净贡献≈0

- 57 回合 / 114 笔委托（占全部 145 笔的 **79%**）。
- 日志 `[统计] L2回合0(滚动年化窗口0) L3回合57 | 综合成本率0.002`。
- 买卖配对看，主要是 `002027.XSHE`（87 笔）、`600938.XSHG`（29 笔）在做日内回转（如 08-31 10:54 卖 200 股 → 13:34 买回 200 股）。
- 对净值的贡献无法在本轮日志中单独观测，但结合 V1.1/V1.2 的判断（综合成本率恒为 0.002、无盈利记录），**净贡献约等于零，却贡献了绝大部分交易摩擦与复杂度**。
