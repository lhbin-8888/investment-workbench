## 二、V1.4 核心改动清单（源码已逐项核对在位）

1. `_l1_refill(total, reason)`：三触发回补——市场开关复位 / 止盈释放后 / 每 5 日兜底（带缺口阈值 15% + 同标的 20 日冷却）；
2. 市场开关**双向**：降档必配回补（V1.3 只降不补）；
3. `_l1_drift_control`：单票浮盈 ≥15% 且超目标权重 → 减至目标权重（保留核心、落袋部分）；
4. `owner_layer` + `l2_qty/l2_entry_px/l2_buy_day`：同代码 L1/L2 共存按股数记账，`_layer_room(..., layer)` 按层算额度；
5. `INTRADAY_T = False`：L3 日内 T 移除（57 回合净贡献≈0）；
6. L2 换池：剔除 3 只科创板高价股（1 手 4.6~6.6 万买不起），换 8 只中低价（1 手 1.2 千~9 千）；
7. L2 信号放宽：回踩 6%→5%、量比 0.8→0.9、RSI 上限 55→58。

关键参数：L1 58% / L2 25% / 单票 ≤10% / 行业 ≤30% / 断路器 −8/−12/−18% / 换手预算 ≈7.5 回合/年。
