# 长线优质股「核心—卫星 + 波段 + 日内T」量化交易策略设计

> 适用标的：从自选股 492 只中筛选出的 16 只长线优质股（见 `05-行业与个股分析/长线选股_20260920/`）。
> 设计目标：**在守住长线复利底仓的前提下，用波段与日内T平滑波动、增厚收益、压低持仓成本**，而非把长线票做成短线博弈。
> 数据快照：2026-09-20。本文为策略设计框架，非买卖建议。

---

## 一、设计哲学与核心矛盾

这 16 只标的的alpha来自**长期质量**（护城河、产业景气、财务健康、估值合理）。策略叠加的交易层**必须服务于长期复利，绝不能反噬底仓**——这是本设计的第一性原理。

历史经验（A股自动化实盘）反复证明，散户量化策略**不是输在选股，而是输在出场与成本**：
- 过度交易 → 印花税（单边0.05%卖出）+ 双边佣金把毛利吃光；
- T+1 误卖当日新仓 → 废单；
- 用昨收当成交基准 → 逆向选择只买到走弱的票；
- 回测用"已选出的好票"测 → 幸存者偏差，数字虚高。

因此本设计把**风控与成本纪律放在收益预期之前**。

## 二、三层资金架构（核心——这是整个策略的骨架）

将总资金切为三层，各层职责隔离：

| 层 | 占比 | 职责 | 可否被T/波段动用 |
|---|---|---|---|
| **L1 长线底仓（Core）** | **58%** | 长期持有16只，捕获复利 | **不可**——T只在其中做"有去有回"的低成本差 |
| **L2 波段卫星（Swing）** | **25%** | 在优质票回调时做中短期价差 | 独立资金池，不碰L1 |
| **L3 现金+T机动（Reserve）** | **17%** | 缓冲 + T周转 + 极端行情补仓 | — |

**关键隔离原则**：L1 是"不动的锚"，Swing/T 只能在 L1 之上做"卖出后必须同日/次日买回"的闭环，绝不允许 T 把核心仓位越做越小。

### 2.1 L1 长线底仓——建仓与再平衡
- **建仓**：按下方"建议权重表"一次性建底仓（或分 3 笔在 1–2 周内打完，降低择时风险）。
- **再平衡**：**季度**再平衡一次，仅在"基本面逻辑破坏"（如护城河削弱、业绩连续不及预期、估值透支）时主动剔除，不因为短期涨跌调仓。
- **硬约束**：单票 ≤ 8%；行业上限（半导体 ≤ 25%、资源能源 ≤ 30%、消费 ≤ 25%、医药 ≤ 20%）。

### 2.2 L2 波段卫星——规则化信号
只在**高流动性子集**（茅台/紫金/海油/迈瑞/药明/金山/兆易/分众/盐湖/珀莱雅）上做，流动性偏弱的高德、中微、拓荆**不纳入波段**，只留底仓。
- **买入信号（回调/均值回归）**，需同时满足：
  1. 价格回落至 20 日或 60 日均线附近（偏离 ≤ -3%）；
  2. 成交量较 20 日均量萎缩（量比 < 0.8，即"地量"）；
  3. RSI(14) ∈ [35, 55]（非超卖恐慌、非过热）；
  4. 大环境非单边下行（见 §四市场开关）。
- **卖出信号**，满足任一即出：
  - 达到目标收益 **+12%~18%**；
  - RSI(14) > 70 或触及 20 日布林上轨；
  - **硬止损 -7%**（一次性清掉该笔波段仓）；
  - **移动止盈**：自最高点回撤 ≥ 8% 即清。
- **持仓周期**：数日至数周；单笔波段占用 L2 资金不超过 1/3，避免满仓追单。

### 2.3 L3 日内T——纯降本工具（不是利润引擎）
A股 T+1 下，日内T只能在**已持有仓位**上做"先卖后买/先买后卖"：
- **触发条件**：当日振幅（ATR14 折算）> 1.5%，且出现明确日内摆动（如冲高至 VWAP+1σ 后回落，或急跌至 VWAP-1σ 后反弹）。
- **规模**：单次 T 动用的股数 ≤ 该标的**持仓的 20%**；单日单票 ≤ 1–2 个回合。
- **铁律**：T 卖出的份额**必须当日（最迟次日）买回**，否则视为减仓违规。
- **最小edge阈值**：单回合预期价差 < 0.4% 不做（覆盖不了冲击成本就是送钱）。
- **现实预期**：对散户，日内T的净贡献常为**负或接近零**，其真正价值是**摊薄 L1 成本基数**——把"做T降本"当练兵，别当提款机。

## 四、风控体系（"风险更低"的落地）

### 4.1 组合级断路器（最重要）
| 触发 | 动作 |
|---|---|
| 组合自高点回撤 **-8%** | 暂停所有 L2/L3 活动，仅持 L1 底仓 |
| 组合自高点回撤 **-12%** | 在 -8% 基础上，砍掉 1/3 的 L1 高位/高估值仓位 |
| 组合自高点回撤 **-18%** | L1 再减半，整体进入防守 |

### 4.2 市场开关（大环境过滤）
- 沪深300 / 中证800 在 **60 日线下方**（宽基下行趋势）→ L2 波段仓位降为 0，只做 L1；
- 在 **120 日线下方**（深度熊市）→ 额外将 L1 砍 20%，现金升至 30%+。
- 用宽基均线作"总开关"，避免在单边下跌里反复抄底被埋。

### 4.3 个股级
- L2 波段硬止损 **-7%** 一次性清；
- **T+1 不可卖**：当日买入份额 `enable_amount=0`，任何卖出判定必须核验可卖量>0，否则跳过（防废单）；
- 单票总敞口（L1+L2）≤ 10%，行业敞口按 §2.1 上限封顶。

### 4.4 成本/换手预算（绑定约束，防过度交易）
A股单边成本 ≈ 佣金0.025%×2 + 印花税0.05%(卖) + 过户费≈0.001%×2 ≈ **0.10%~0.13% / 回合**。
设定**年度成本预算 ≤ 1.5%**，则年化可承受回合 ≈ `1.5% ÷ (2×0.11%) ≈ 7 回合/年`（全组合口径）。
→ 这不是"尽量多交易"，而是"**每年只有约 7 次完整回合的额度**"，倒逼只做高确定性信号。任何新信号必须先证明：预期edge > 成本×安全系数(≥3)。

## 五、收益与风险预期（诚实表述）

- **主收益来源**：L1 长线复利（这16只的质量溢价）。波段+T 是**辅助**，目标是在震荡市贡献低个位数年化增厚，并**降低 L1 成本基数、压缩回撤**。
- **现实边界**：复盘大量A股自动化策略，overlay 在扣除成本后净贡献常有限；真正的价值在于**风险平滑**（熊市少亏、震荡市有现金流），而非收益倍增。
- **最大风险**：① 过度交易吃掉复利；② T 误操作把核心做丢；③ 在单边市里波段抄底。§四的三道防线正是针对这三点。
- **结论**：本策略追求的是"**同等或更低的波动下，略高的风险调整收益**"，不是最高绝对收益。若想要最高收益而不在乎波动，直接满仓 L1 长持即可——策略的意义在于"拿得住、睡得着"。

## 六、自动化落地路径（"自动交易"怎么实现）

### 路径A：券商条件单 / 网格（通达信、券商APP）——**推荐起步**
- 对 L2 流动性子集设**网格条件单 / 定价买卖条件单**，触发自动成交，券商服务器执行，零代码。
- 优点：落地快、无平台限制、不踩 T+1/涨跌停口径坑。
- 局限：只有网格/条件逻辑，难做"组合级断路器 + 市场开关"的联动。→ 用**人工周度巡检**补这层。

### 路径B：PTrade / QMT（券商托管 API）——**全自动化**
- 把 §二~§四 全部规则写成策略（initialize / before_trading_start / handle_data / 风控巡检）。
- **上线前必须逐条确认的平台口径**（猜错=静默错）：
  - `volume` 单位是**股**不是手；代码后缀 `.SS/.SZ/.BJ`；
  - 持仓 `enable_amount`=可卖量(T+1)，`current_amount`=总持仓，当日新仓只能看后者；
  - 涨跌停按板区分：主板10% / 创业板科创板20% / 北交所30% / ST 5%；
  - 成本模型**必须含印花税(卖出0.05%) + 双边佣金**，别用漏项数字；
  - 回测里当日价只能走 `data` 参数或分钟线，直接读 `close[-1]` 会拿到昨收；
  - 托管机房**无外网**，所需数据（行业映射等）必须随策略文件带上去。
- 默认 `TRADE_ENABLED=False`：先跑信号模式 3–5 个交易日核对日志 → 模拟盘 → 小资金实盘。

### 路径C：通达信指标 + 人工执行
- 写公式出买卖点箭头，人工下单。控制最强、自动化最弱，适合先验证逻辑。

**建议路线图**：
1. **第1–2月**：路径A（条件单/网格做 L2）+ 严格记录的手动 T 纪律 + 周度人工风控巡检，验证信号质量。
2. **第3月起**：若信号稳定、回撤可控，迁移到**路径B（PTrade/QMT）**做 L2+L3 全自动化，L1 仍人工季度再平衡。
3. 全程保留 §四 断路器的人工兜底开关。

## 七、回测与验证纪律（避免自欺）

- **幸存者偏差**：这16只是"已选出的好票"，回测必偏乐观。结论必须打折，且用**中证800（核心大盘）/ 中证1000（成长波段）**做风格匹配基准。
- **成本必须真实**：任何回测都内置佣金+印花税+滑点（建议单边 0.1%~0.15% 滑点），否则"盈利"是幻觉。
- **先证瓶颈再改参**：若改了N版出场收益不动，先用"买了之后什么都不做 vs 基准"算**超额**，确认是选股还是出场的问题，再动手（详见 `10-策略回测` 的归因方法论）。
- **小步验证**：规则改一项、回测一项、对照一项，保留"原版参数复现"预设做归因基线。

## 八、一句话总结

> **58% 长线不动如山（L1）+ 25% 波段择机而动（L2）+ 17% 现金/T 机动（L3）；用市场开关和 -8%/-12%/-18% 三级断路器锁住下行，用"每年约7回合"的成本预算锁住手痒。T 是降本练兵不是提款机，核心仓位一根毛都不能被做丢。**
