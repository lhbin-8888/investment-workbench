## 二、本策略已落实的硬规则（对照 ptrade-strategy-dev 技能）

- [x] Python 3.5 兼容：无 f-string、无类型注解、无 `os` 模块、无外网请求
- [x] `initialize` 内 `set_universe(STOCKS)`：PTrade 框架要求注册标的后 `handle_data` 的 `data` 才带个股行情（已补，缺则 L3 日内T 整段失效）

- [x] 涨跌停按板区分：`_plate_pct` 对 30/68→20%、8/4→30%、ST→5%、其余 10%（L3 卖在涨停附近会被 `enable_amount`/限价自然挡住；如需显式跳过涨停可加 `_near_limit` 判断）
- [x] 成本含印花税：单边 0.05%（2023-08-28 起），佣金双边 0.025%，滑点 0.05%；`COST_PER_TURN` 参与换手预算
- [x] 回测当日价口径：L1/L2 信号在 `before_trading_start` 用**已完成数据**（末根=昨收）；L3 盘中价显式标注来源 `[口径]`
- [x] 盈亏比自洽：`L2_STOP_PCT(7%) <= L2_TAKE_PCT(14%) * 0.5` → 自检打印 PASS
- [x] 出场分级闸门：风险类（L2 硬止损）只设下限 09:45；趋势类（L2 止盈/超买/移动止盈）盘前用完成数据执行
- [x] 两段式止损已**弃用**：统一单段一次性清仓 + 策略自有成本价 `entry_px`（防平台摊薄口径改写）
- [x] 组合级风控：三级断路器（-8%/-12%/-18%）+ 沪深300 均线市场开关；断路器在 `_do_buy_value` 中**独立拦截所有方向性买入**（L1 季度再平衡补仓也受控；L3 日内T回补不走此函数，不受影响）
- [x] 市场开关**双向可复位**（2026-09-21）：短均线(60)回归即恢复 L2 新开；长均线(120)回归且连续 `MKT_RESET_CONFIRM_DAYS` 日（默认 1）后档位复位为 0，再次跌破可再减仓；均线数据缺失时维持当前档位、不误复位（`_index_below_ma` 三态返回）
- [x] 换手预算：`MAX_ANNUAL_TURNS` 按"年度成本预算 ÷ 单回合成本"换算，买卖双侧记账，超阈暂停新开
- [x] 任何接口降级都 `log.warning`，绝不静默换口径（`_hist_lists` / `_cur_price` / `_get_positions` / `_account` 全有告警）
- [x] L3 日内T 闭环：只卖可卖量、当日必回补（`14:50` 强制平），**不增隔夜仓、不碰 L1 核心**
- [x] 行业上限约束（SECTOR_MAX=30%）：在 `_do_buy_value`（L1/L2 建仓唯一入口）下单前，按 `SECTOR_OF` 聚合所属细分行业当前总市值占比，超阈**拒单/减额**；L3 日内T 走独立闭环（隔夜净仓不变）豁免，避免误杀。未配置行业的标的跳过约束但 `[sector-cap]` 告警一次

## 三、上线前手动核对动作

1. **信号模式跑 3~5 日**：`TRADE_ENABLED=False`，看日志是否出现预期 `[signal-buy]`/`[信号-卖]`，以及 `[口径-降级]`（若 L3 关说明回测无盘中价，正常）。
2. **核对 T+1 拦截**：制造"当日买入"场景，确认日志打印 `可卖为0(T+1未交收)...顺延次日`，无废单。
3. **核对成本预算告警**：制造高频触发，确认 `[换手预算]` 告警并产生暂停。
4. **核对断路器**：模拟组合回撤 >8%/12%/18%，确认分级减仓日志与动作。
5. **小资金实盘**：`TRADE_ENABLED=True`，单票极小仓，盯 1~2 周无异常再放大。
6. **L1 季度再平衡**只在第 60 个交易日触发一次，确认不会每天调仓（避免把长线核心做成短线）。
7. **核对行业上限**：制造某细分行业（如"集成电路设计"=兆易+澜起）已接近 30% 场景，确认日志打印 `[sector-cap]` 减额/拒单；L3 日内T 不受影响。
8. **核对断路器拦 L1**：触发 -8% 断路器后，确认 L1 季度再平衡不再补仓（日志无 `[signal-buy]`，或仅有 L3 回补）；熔断解除（回撤收敛）后恢复。
9. **核对 L1 最短持有**：对某已持仓 <5 日的票制造"低配"场景，确认日志打印 `[L1] ... 持仓不足5日，跳过再平衡追买`，不追买。
10. **核对市场开关复位**：确认指数回到 120 日线上方连续 `MKT_RESET_CONFIRM_DAYS` 日后打印档位复位日志，且此后**再次跌破** 120 日线时能**再砍两成**（验证单向闩锁已解除）。

### ⚠️ 尚未解决、需要决策的结构性问题

**10 万本金下组合最大仓位只有 60%**（可买标的 6 只 × 单票上限 10%），名义目标 83%，资金利用率仅 72%。
且 **L2 标的池与 L1 完全重叠**，L1 经资金再分配后单只约 9.7%，留给 L2 的单票空间合计仅约 **1.3%**（L2 名义目标 25%）。

三条出路（V1.1 的 `[资本适配-建议]` 也会在日志中提示）：

1. **放大本金** —— 50 万时 L1 单票 1.8 万，16 只里 15 只可建仓（仅茅台除外）；
2. **压缩标的池** —— 剔除高价股，保留能建仓的 6~8 只；
3. **调高 `SINGLE_MAX`** —— 当前 10%，提到 20% 可让 L2 有独立空间，代价是分散度下降。

**资金再分配只能解决「预算被高价股作废」，解决不了「单票上限 × 可买标的数」这个总量硬顶。**

## 九、V1.3 修复与验证（2026-09-22）
