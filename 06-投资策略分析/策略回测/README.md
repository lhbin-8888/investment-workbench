存放量化策略 / 交易策略的回测代码、回测结果与参数优化记录。

```

├─ README.md                    本说明
├─ 策略回测.md                   功能模板（四段式）
```

## 内嵌工具：策略回测工作台

- **入口**：工作台左侧「投研研究 → 策略回测」，以 iframe 嵌入 `工具/bt.html`
- **形态**：默认 9 个分区以九宫格（3 列）排布，收起＝一格总览，点宫格即展开编辑（展开态横跨整行）
- **每个分区包含**：策略名称（手动填写）/ 策略程序文件（本机选择或按路径载入）/ 策略说明与使用文档 / 策略回测情况（12 项指标）/ 策略风险与注意事项
- **持久化**：内容存本机浏览器（localStorage），支持导出 / 导入 JSON
- **报告归档**：单分区可「导出本策略报告」或「导出并归档到文档列表」，报告进本板块下方文档列表

## 推荐文件命名规范

```

```

## 建议内容要素

- 策略逻辑与信号定义（选股 / 择时 / 仓位）

- 回测区间、累计收益、年化、基准与超额
- 最大回撤、夏普、卡玛、胜率、盈亏比、换手率、交易次数
- 失效归因与版本迭代说明
- 风险与注意事项（过拟合、流动性、容量上限）
