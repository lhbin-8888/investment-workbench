## 一、V4.8 要解决什么

V4.7 复盘的结论是：**出场时点修对了，但出口换了名字继续砍人**。四条硬证据：

| 现象 | 数据 |
|---|---|
| 破均线被治住 | 9 笔全部成交于 14:45 尾盘确认 ✅ |
| 出口被 ATR 止损接管 | 16 笔，均值 **−5.57%**，全部落在 −5.0%~−10.5% |
| ATR 止损退化为固定 5% | `clamp(1.8×ATR/成本, 0.03, 0.05)`，热点票 1.8×3.5%≈6.3% **被上限截断** |
| 折年换手不降反升 | 23.7 → **28.2 次**；成本 2.59% → **3.08%** |
| 双护栏仍 100% 空转 | **42/42 笔**走 `assumed(+1.0%)` |
| 仓位被自己规则锁死 | 产业链簇拦截建仓 **17 次**，实际只买 1~2 笔 |
| 主跌段无避险档 | 5/13~6/15 跌 10.62%，其间 14 笔止损，市场开关 **0 次触发** |

| **P0-3** | 新增 `[口径-探测]` | — | 打印 data 键样本 + 命中数，下轮可定位 |

**两段式止损规则**（本版核心设计）：

```
首次触发（浮亏 ≤ -阈值，且 now ≥ 09:45）
   └─ 仓位 ≥ 2 手 → 减半，记 stage1 = 当日
   └─ 仓位 < 2 手 → 一次清仓（结构上无法分批）

减半之后：
   ├─ 同日跌破 阈值×1.5   → 立即清剩余（尾部风险兜底）
   ├─ 同日未深跌          → 等次日（不重复动作、不刷屏）
   ├─ 次日仍触发          → 清剩余（"两段式第二阶段"）
   └─ 浮亏收窄至 阈值×0.5 以内 → 撤销 stage1 标记，重新武装
```

### P1（收益弹性）

| 项 | 改动 | 现值 |
|---|---|---|
| P1-1 | `CLUSTER_JACCARD` / `CLUSTER_MAX_WEIGHT` | 0.3 → **0.5** / 0.40 → **0.50** |
| P1-2 | `PARTIAL_TAKE_PCT` | 0.12 → **0.10**（V4.7 实测 7 笔全挤在 12.0~13.0%，锁利太晚） |
| P1-3 | 新增市场避险档 | `REGIME_RISK_OFF_SCALE=0.5` / `REGIME_RISK_OFF_MAX_NEW=1` / `REGIME_RISK_OFF_MA_FAST=5` |
| — | `TRAIL_PCT` | **保持 0.10**（用户指定值，本版未动） |

避险档判定（任一成立）：① 沪深300 收盘 < MA20；② MA5 < MA20 且收盘 < MA5。命中后**单票仓位 ×0.5、每日只建 1 笔**——是"减速"不是"急停"（V4.1 那个"全停"开关曾误杀唯一候选）。

### P2（可观测性）

- `[成交] 本日递交委托 N 笔 / 受理 M 笔 | 候选 X 只 | 避险档=ON/off | 单票缩放=x.xx`
- 两段式三态各自独立日志（减半 / 第二阶段 / 撤销），均走 `_noise_once` 每日去重

## 四、已知事项与风险（必读）

1. **P0-3 是否真修好，只能由下一轮回测回答。** 本版做了两件事：注册 universe（治根因）+ 加诊断日志（可定位）。若下轮 `[口径-来源]` 仍是 `assumed=100%`，说明该回测引擎的 `data` 不受 universe 控制——那就该换思路（例如改用开盘价作为假设价基准），不要再在同一处打转。

2. **两段式止损会拉长单笔持仓周期**，方向上有利换手压降，但**单笔最大亏损可能扩大**（阈值放宽到 12% + 首次不砍完）。若回测出现"单笔亏损 > 12%"的样本，即为 `STOP_STAGE1_HARD_MULT` 未及时兜住，需复查。

3. **换手熔断（60 交易日 / 6 次）在 39 天回测中仍不会触发** —— 它是实盘长周期护栏，别把"没触发"当 bug 或当成果。回测内的换手压降靠 P0-1（首次不砍完 → 出场笔数降）+ P0-2（每日 2 笔）。

4. **避险档在主跌段会主动降速**，若回测区间正好是"深跌后急涨"，半仓会显著拖累收益。这是有意的取舍，不是缺陷。

5. **`TRAIL_PCT=0.10` 未动**（尊重你的指定）。若要测试"赢仓多跑"，单跑 `0.10 / 0.12` 两档对比，不要与其他改动混在一次回测里。
