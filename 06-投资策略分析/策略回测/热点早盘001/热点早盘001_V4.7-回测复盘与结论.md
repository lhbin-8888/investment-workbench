## 五、五个问题（按收益弹性排序）

### 🔴 问题 1（首要）：ATR 止损退化成"固定 5% 止损"，垄断了出口

**事实**：31 个平仓事件中，**ATR 止损 16 笔（52%）**，出场时盈亏全部落在 **−5.0% ~ −10.5%**，均值 **−5.57%**；其中 8 笔持仓仅 1 个交易日。

**根因（参数级）**：
```
止损阈值 = clamp( 1.8 × ATR(14) / 成本 ,  0.03 , 0.05 )
```
- `ATR_STOP_MULT = 1.8`；热点票 ATR(14)/价格 通常 3%~5% → `1.8 × 3.5% ≈ 6.3%`
- `ATR_STOP_MAX_PCT = 0.05`（**V4.6 从 0.08 降到 0.05**）→ 6.3% 被截断到 5%
- 结果：**16 笔全部走到上限 5% 出局**，ATR 的"自适应"完全失效，等价于一根固定 5% 止损线

**为什么这是致命的**：信号日的选股条件是"涨幅 4%~5% 的启动票"，这类票次日日内 ±5% 波动属常态噪声。用 5% 止损必然被反复震出，且**每次出局都要付出一次双边成本（0.7%）**，还打断了趋势。

**量级**：16 笔 × 约 15% 仓位 × (−5.57%) ≈ **−13.4% 权益**；同期分批止盈 7 笔 × 15% × (+12.36%) ≈ **+13.0% 权益**。两笔账基本对冲——这就是收益归零的直接原因。

### 🔴 问题 2：换手不降反升，成本吃掉全部毛利

- 折年双边换手 **23.7 → 28.2 次**（+19%），区间成本 **2.59% → 3.08%**（折年 16.6% → 19.7%）
- **毛利（区间）= 收益 −2.12% + 成本 3.08% = +0.96%** —— **首次转正**，但只有 0.96%，被成本完全覆盖
- 换手上升的原因不是止损更频繁（出口笔数 35→38 基本持平），而是 **V4.6 提高仓位利用率的两处改动**：`MAX_NEW_POSITIONS_PER_DAY 2→3`、`DIFFUSE_POSITION_RATIO 0.10→0.15`

> **这是一对方向相反的目标在打架**：V4.7 的 P0-2/P1 想"提仓位"，V4.5 的诊断要"降换手"。**在毛利只有 1% 的情况下，提仓位 = 提换手 = 提成本，等于自杀。**

**硬约束算术**：成本 19.7%/年 → 要正收益，年化毛利必须 > 19.7%。当前毛利折年约 6.4%，**差 3 倍**。

### 🟠 问题 3：双护栏全程空转（与 V4.4 同源的旧疾，未修复）

42/42 笔建仓价 = `T-1收盘 × 1.010`，限价 = `min(1.010 × 1.02, 1.030) = T-1收盘 × 1.030`。

- **"走弱不接刀"（下限 −1.5%）从未生效**：因为用的是假设价，永远落在护栏内
- **"涨过头不追"（上限 +3%）退化为限价规则**：只有当天全天高于 +3% 才被挡
- 这直接解释了**拒单率为何调不动**：能成交的 = 当天盘中回落到 +3% 以内的票；拒单的 = 全天强于 +3% 的票。**买得到的样本被系统性筛选成"次日不够强"的那批（逆向选择）**
- 根因：`_capture_intraday(data)` 在回测中取不到 `data.get(code).close`，09:30/09:31 两次机会均未捕获 → `g.intraday_px` 为空

### 🟠 问题 4：产业链簇约束过严，把仓位锁死在 2~3 只

`CLUSTER_JACCARD = 0.3` 且同簇仓位 ≤40%，但本区间主线（稀缺资源 / 元件 / 中芯概念 / 汽车芯片）**互相高度重叠**：

```
[买入] 元件   板块与现有持仓同产业链簇(重叠N只) → 同簇仓位将超 40%，跳过   ×6
[买入] 稀缺资源 板块与现有持仓同产业链簇 → 跳过                        ×5
[买入] 中芯概念 板块与现有持仓同产业链簇 → 跳过                        ×4
[买入] 东数西算 板块与现有持仓同产业链簇 → 跳过                        ×2
```

候选端每天入选 5.3 只，实际只买 1~2 笔（19 个建仓日 / 39 天），**这道约束是首要拦阻**。结果：仓位利用率 56.5%，看似比 V4.5 的 40.4% 高，但仍**远低于设计目标 90%**。

### 🟡 问题 5：市场级开关在主跌期全程未触发

5/13~6/15 净值跌 10.62%，期间 16 笔止损中的 14 笔集中在此段。但日志中 `market_regime_ok()` **没有任何一次触发停建仓**（无相关日志），换手熔断同样 0 次（60 交易日窗口 > 39 天回测，属预期）。

**即：最大的那段亏损，策略没有任何"避险档位"可用。**

## 六、V4.8 建议（按优先级）

### P0 —— 决定策略能否转正

1. **放宽 ATR 止损，让它真正"自适应"**
   - `ATR_STOP_MAX_PCT` 0.05 → **0.12**；`ATR_STOP_MIN_PCT` 0.03 → **0.05**
   - 或改为**收盘价确认 + 2 个交易日宽限**（日内跌破不算，收盘确认才执行）
   - 预期：止损笔数下降、持仓延长、换手与成本同步下降
   - ⚠️ 风险：单笔亏损上限放大。建议同时保留"单票亏损 −12% 硬顶"作为最后防线

2. **把换手压到 ≤12 次/年（成本 ≤8%）**
   - `MAX_NEW_POSITIONS_PER_DAY` 3 → **2**（回退 V4.6 前）
   - `DIFFUSE_POSITION_RATIO` 0.15 → **0.12**
   - 这两项是"提仓位"的手段，在当前毛利水平下方向是错的，应优先让位于"降成本"

3. **修日内价捕获，让双护栏真正生效**
   - 需实测 PTrade 回测 `handle_data(context, data)` 中 `data` 的实际类型与字段（`data.get(code)` 返回对象是否有 `close`/`price`）
   - 备选：改用 `get_current_data()` 的 `last_price`；若回测仍不暴露，则应**放弃模拟假设价**，改为回测器支持的撮合口径（否则一切入场价分析都是自欺）

### P1 —— 提高毛利

4. **放宽产业链簇约束**：`CLUSTER_JACCARD` 0.3 → **0.5**，或同簇上限 40% → **60%**。当前把"科技单主线"行情整个锁死
5. **分批止盈是唯一稳定正 alpha（7 笔全部 +12%+）**：可考虑 `PARTIAL_TAKE_PCT` 12% → **10%**，并搭配 `TRAIL_PCT`（现 0.10）进一步放宽到 0.12，让剩余半仓跑更远
6. **市场级避险档**：指数跌破 MA20 且连续 2 日 → 当日不建仓 + 仓位上限降至 3 只。5/13~6/15 那段至少能减半

### P2 —— 可观测性

7. 日志补 `[止损明细] 阈值计算值=X% 截断后=Y% ATR=Z`，直接把"ATR 退化为固定止损"暴露在日志里
