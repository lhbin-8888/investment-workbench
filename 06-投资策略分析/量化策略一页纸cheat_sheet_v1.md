# 量化策略一页纸 Cheat Sheet（v1）

> 来源：投研工作台本地策略沉淀——热点追踪 v3~v5、长线股三层量化 v1.5~v2.0、热点判定/操作技能、个股估值技能、历次回测复盘。
> 内部操作参考，非投资建议。每条规则均来自实盘/回测验证过的打法或踩坑。

---

## 总纲（三句话）
1. **输在出场与成本，不在选股**——风控与成本纪律放收益预期之前。
2. **先证瓶颈再改参**——改 N 版收益不动，先算"买入后啥都不做 vs 基准"的超额。
3. **无未来函数**——全链路只用已收盘数据，实时价仅作护栏。

## 🔥 热点线

**筛选｜真热点 = 五维共振**（政策·资金·情绪·形态·联动）
- 全满足=主线主升；满足≥3条=真热点。三类伪热点直接排除：①一日游纯题材 ②高位退潮老热点 ③冷门无联动。
- 利好三问占其二才成立（覆盖全行业？有持续性？改业绩预期？）。
- **⚠️ 板块跌破 20 日线 = 退潮，一票否决**（独立成立，不参与计分）。

**板块｜三阶段动作不同**
| 阶段 | 选股 | 动作 |
|---|---|---|
| 启动 | 流通≤50亿·股价≤10元 | 止损3-5%；政策后3天内抢跑 |
| 扩散 | 50-200亿·业绩中盘 | 回10日线加仓 ← **只买这阶段** |
| 衰退 | — | 减仓离场 |
- 仅扩散可买（`REQUIRE_DIFFUSE_ENTRY`）；扩散≥5日末段不买；退潮需连续2日确认。

**选股｜三层漏斗**：角色分层(龙头/中军/补涨)>边缘剔除 → 四硬指标全过(阶段匹配·业绩支撑·资金连续·站10日线) → 估值性价比排序。
- 量化过滤：上市≥60日·成交≥3亿·站MA20·量比≥1.2·非ST。只买前2-3只；**同板块≤2只合计上限**。

**买点**：不追涨停；涨幅主板3-4%/双创6-8%｜双护栏(<昨收-1.5%不接刀、>昨收+3%不追)｜高开>2%放弃｜昨日涨停<25家不开仓｜混合信号(T-1定板块+T日开盘确认均涨≥1.5%)｜窗口09:35-10:00回踩买｜V5路径B尾盘选强(均涨≥2.5%)→次日回踩买。

**卖点**：+10%减半→+15%清仓，减半后保本止损｜动态移动止盈(回撤随浮盈收窄·下限4%·峰值回撤>8%清)｜ATR止损(成本-1.8×ATR·下限5%/上限8%)｜破3日线快出·破20日线退潮清｜时间止损≥5日｜单票硬止损-5%。

## 📈 长线线

**架构｜三层资金**
| 层 | 占比 | 纪律 |
|---|---|---|
| L1 核心底仓 | 58% | 不动如山；单票≤8%；行业封顶(半导体≤25%/资源≤30%/消费≤25%/医药≤20%) |
| L2 波段卫星 | 25% | 回调做价差；独立资金池 |
| L3 现金+T | 17% | 缓冲+降本；卖出必当日/次日买回(闭环) |

**估值选尺**：成熟PE+DCF｜成长PEG｜亏损PS｜周期PS+PB｜金融PB+股息｜无形资产PB失真(破1反是机会)。两把尺交叉验证；区间非点位；永续1-3%。

**买点**：L2四条件同触发——回20/60日线(偏离≤-3%)+量比<0.8地量+RSI∈[35,55]+非单边下行。L3日内T——振幅>1.5%且明确摆动；单票≤1-2回合/日；价差<0.4%不做。

**卖点**：L2目标+12~18% / RSI>70或触布林上轨 / **-7%硬止损** / 自高点回撤≥8%；横盘≥8日±1.5%窄带退出。

**⚠️ 组合断路器（最重要）**
- **-8%** → 停 L2/L3，仅持 L1
- **-12%** → 砍 1/3 高估值 L1
- **-18%** → L1 再减半防守
- 市场开关：宽基<60日线→L2=0；<120日线→再砍L1 20%、现金≥30%

## 仓位 & 平台红线
- 同板块≤2只·总仓≤5只·单票≤18%·留10%现金。
- 年成本预算≈**7回合**(单回合0.10-0.13%)；新信号先证 edge>成本×3。
- 小资金别硬套大盘蓝筹池（整手粒度致分散化失效：30万+0.15% vs 10万-4.97%）。
- **PTrade 红线**：`volume`是股·`enable_amount`=T+1可卖量·`close[-1]`是昨收·成本含印花税(卖0.05%)+双边佣金·先信号模式3-5日→模拟盘→小资金实盘。
