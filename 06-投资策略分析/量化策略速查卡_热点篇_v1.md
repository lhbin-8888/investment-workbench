# 量化策略速查卡 · 热点篇（v1）

> 拆分自《量化策略经验手册_值得保存的操作方法.md》。
> 来源：热点追踪 v3~v5（`quant/hotspot/`）、热点判定/操作技能（`rd-hotspot-vetting` / `rd-hotspot-play`）、个股估值技能、V4.5~V4.8 回测复盘。
> 用途：盘中/盘前翻这张卡定"板块→个股→买点→出场"。每条标出处便于回溯。
> 性质：内部操作参考，非投资建议。

---

## 总纲三条铁律（先记住）
1. **量化策略不是输在选股，是输在出场与成本。** 风控与成本纪律放在收益预期之前。
2. **先证瓶颈再改参。** 改 N 版出场收益不动，先算"买入后啥都不做 vs 基准"的超额，确认是选股还是出场问题再动手。
3. **无未来函数。** 全链路只用已收盘数据，实时价仅作建仓护栏。

## 一、热点筛选（真假鉴别）
> 来源：`rd-hotspot-vetting`

- **真热点 = 政策、资金、情绪、形态、联动性 五维共振**，不是某只股票涨停。
- **先排除三类伪热点**（命中任一类直接排除）：
  1. 纯题材、无业绩无政策、靠消息炒、涨一天跌三天；
  2. 前期已大涨、高位放量、龙头断板、资金出逃的老热点退潮期；
  3. 涨停少、成交低、无板块联动的冷门题材。
- **利好三问验逻辑**：利好覆盖全行业还是只落个别公司？有持续性还是放完就完？真能改变行业业绩预期吗？三者占其二才具备热点基础；只中一问或零中 = 资金瞎炒，排除。
- **资金量级标尺**：板块日均成交额进全市场前 10；主力连续 2–3 日净流入；换手健康放大、非单日天量长阴。科技板块单季净流入超 200 亿对应指数涨 40%、融资余额 100→150 亿对应涨 15%——连零头没有的当不了一线热点。
- **五维计分**：政策/事件、资金、梯队联动、形态、情绪辨识度逐维打勾；满足 3 条以上 = 真热点，全满足 = 主线主升。
- **⚠️ 退潮一票否决（全卡最重要的一条）**：板块指数**跌破 20 日线 = 热点退潮**，独立成立、不与其他维度加权、不参与计分。跌破当天翻结论；20 日线收复前，反弹一律不算热点复活。

## 二、板块判断（阶段 + 梯队）
> 来源：`rd-hotspot-play` + 热点策略 `classify_stage` + V4.5~V4.8 复盘

- **三阶段，动作不同**：
  | 阶段 | 特征 | 选股 + 动作 |
  |---|---|---|
  | 启动期 | 刚突破、底部 | 流通 ≤50 亿、股价 ≤10 元低价小票（弹性大）；当天设 3%–5% 止损；政策发布后 3 天内抢跑 |
  | 扩散期 | 热点走出来、市场都认 | 50–200 亿中盘、业绩优良估值合理；回调到 10 日线加仓吃兑现 |
  | 衰退期 | 退潮信号 | 减仓离场，不再加仓 |
- **关键经验（V4.5 根因复盘）**：回测 13 笔平仓仅 2 笔盈，**亏损首因是"入场追滞后热点"**。对策：收敛为"**仅扩散可买，启动一日游一律不买**"（`REQUIRE_DIFFUSE_ENTRY=True`）。
- **梯队完整度**：总龙头（连板开高度）+ 中军大票（托底线）+ 跟风补涨（低位首板二板）+ 板块指数同步走强。四位置齐才是真热点；孤零零一只涨停、其他不涨反跌 = 个股行情不是板块热点。
- **退潮确认要连续**（V4.6 `RETREAT_CONFIRM_DAYS=2`）：单日 ≤1 家易误杀，用"连续 2 日全部 ≤1 家 + 前 3 日峰值 ≥4 家"判结构性退潮；正常 2→1 波动不触发联动清仓。
- **扩散末段防接盘**：扩散持续 ≥5 日（路径B 隔夜再老一天 →4 日）末段直接不买；偏好早期——扩散 ≤3 日且未拐头标记 `fresh` 排序优先（`PREFER_EARLY_DIFFUSE`）。

## 三、个股选择（热点股）
> 来源：`rd-hotspot-play` 三层漏斗 + 热点策略 v3/v4 个股四过滤

### 3.1 三层漏斗（板块内优选）
1. **角色分层**：总龙头 / 中军大票 / 跟风补涨 / 边缘票（边缘剔除）。启动期主打龙头+低位补涨（要弹性），扩散期主打中军大票（要确定性）。
2. **四项硬指标全过才进候选池**（任一不过即淘汰，不进买入名单）：
   - 阶段匹配：启动看流通 ≤50 亿、股价 ≤10 元；扩散看 50–200 亿 + 业绩支撑。
   - 业绩支撑：营收/净利增速为正且不减速，或有已公告订单、产能落地。
   - 资金连续：主力连续净流入，龙虎榜有机构或活跃游资；单日对倒放量次日净流出不算。
   - 形态位置：站上 10 日线、回调不破关键均线；高位钝化横盘、量价背离剔除。
3. **估值性价比排序**：同行业 PE/PB 历史分位（低优先）、PEG、距关键均线安全垫。**跨类型不硬比估值**（资源端 vs 加工端、周期 vs 成长尺子不同，比出的"便宜"是假的）。
- 只买前 2–3 只；**同板块设合计仓位上限**（同板块个股高度相关，买三只和买一只风险差别没直觉大）。

### 3.2 量化硬过滤（热点追踪 v3/v4 个股四过滤）
- 上市 ≥60 日；当日成交额 ≥3 亿；剔 ST / 退市整理。
- 封板判定自适应：主板 10% / 双创 20% / 北交所 30%（±2%）。
- 放量确认：量比 ≥1.2（v3 选股口径）；量比 <0.8 视为"地量"（长线股 L2 买点要求）。
- 必须站上 MA20（`REQUIRE_ABOVE_MA20`）。
- **分时回踩过滤**：10:30 快照价 ≥ 当日开盘价才买（日内动量未转弱，`BUY_ONLY_IF_ABOVE_OPEN`）——"买在日内绝对高点"判定已弃用，会系统性误杀。

## 四、买入条件（热点）
> 来源：热点策略 v3/v4/v5 参数护栏

- **不追涨停/不追一字板**（`ALLOW_LIMIT_UP_BUY=False`）；涨幅区间按板块分档、收窄上限降追高（主板 3%~4%、双创 6%~8%）。
- **双护栏（基线）**：快照价 < 昨收×(1-1.5%)（走弱不接刀）或 > 昨收×(1+3%)（涨过头不追）均放弃。
- **高开追高放弃**：T 日开盘较 T-1 收盘高开 >2% 放弃（`OPEN_CHASE_PCT=0.02`）。
- **市场开关**：昨日池内涨停 ≥25 家才开新仓（`MARKET_ZT_FLOOR`）。
- **混合信号（V4.7 标准打法）**：T-1 收盘定"板块"（慢变量、噪声最低）+ T 日开盘确认"择时"——板块均涨 ≥1.5% 或开盘涨停/逼近 ≥1 家才判"确认"，未确认当日不开仓；实时数据缺失时安全降级为"全部通过"，不阻塞建仓。
- **窗口化建仓（V4.7）**：固定 10:00 单点 → 改为 09:35–10:00 滚动扫描，回踩到位即买；价格类护栏临时不达标者"保留候选"留待下次（非破坏性），错过尖峰等回踩。
- **尾盘选股 + 次日早盘买（V5 路径B）**：15:05 收盘用全天定型数据选强（板块均涨 ≥2.5% 才认"全天真强"，滤日内假强）→ 跨夜留尾盘池 → T+1 09:35–10:30 回踩买。隔夜防 stale：T+1 09:30 对尾盘池重确认，死板块剔除。
- **建仓执行**：按可用现金、留 10% 缓冲、整百股（科创 200 股）；强度分档分配（强信号更高权重，单票上限 30% 防过度集中）；分配金额不足最小手数则跳过、空出仓位。

## 五、止盈止损（热点）
> 来源：热点策略 v3 `monitor_risk` + V4.6 动态止盈

- **分批止盈（v3）**：浮盈 +10% 减半（仅触发一次）→ 浮盈 +15% 或破线清仓；减半后启用**保本止损**（回落到成本价清仓，锁定已落袋利润）。
- **动态移动止盈（V4.6 `DYNAMIC_TRAIL`）**：回撤带宽随浮盈收窄（浮盈越大锁越紧，下限 4%），峰值回撤 >8% 清仓——让利润奔跑 + 保护。
- **ATR 动态止损**：成本 -1.8×ATR 清仓；下限 5%/上限 8% 防隔夜跳空瞬时刺穿。
- **破线出场**：破 EXIT_MA(3 日) 清仓（更快出场、缩短亏损持有期）；破 RETREAT_MA(20 日) 退潮清仓（兜底）。破 5 日线加 1.5% 缓冲（`MA5_BREAK_MARGIN`）防微破即砍。
- **时间止损**：亏损票持有 ≥5 日 → 主动退出释放资金。
- **单票硬止损**：热点 -5%（v3，原 3% 在热点波动下太紧）。

## 六、仓位（热点相关）
- **同板块高度相关**：每板块 ≤2 只、总仓 ≤5 只、单票 ≤18%（留 10% 现金）；同板块设合计上限。
- **资金规模要匹配标的池（实测教训）**：同版本同区间 **30 万 +0.15% vs 10 万 -4.97%**，差异不在参数、在整手粒度导致小资金分散化失效、权重畸变——小资金别硬套大盘蓝筹池。

## 七、PTrade 工程纪律（热点相关）
> 来源：热点策略 v3 启动自检 + V4 复盘 §9

- **托管机房约束**：Python 3.5、无外网、无 os、无高级库；所需数据（行业映射等）必须随策略文件带上去。
- **口径坑（猜错 = 静默错）**：`volume` 单位是**股不是手**；代码后缀 `.SS/.SZ/.BJ`；持仓 `enable_amount`=可卖量(T+1)、`current_amount`=总持仓，当日新仓只能看后者；涨跌停按板区分（主 10%/双创 20%/北交所 30%/ST 5%）。
- **回测当日价**：只能走 `data` 参数或分钟线，直接读 `close[-1]` 拿到的是昨收；成交量单位启动自动校准（用大盘蓝筹基准）。
- **成本模型必须含印花税(卖出 0.05%) + 双边佣金**，别用漏项数字；滑点建议单边 0.1%~0.15%（追高品种偏乐观要加压）。
- **上线三步走**：默认 `TRADE_ENABLED=False` → 先跑信号模式 3–5 日核对日志 → 模拟盘 → 小资金实盘。
- **启动自检防"静默空转"**：关键接口缺失、成交量单位、当日 bar 口径、取数失败都要打 ERROR/诊断日志，不谎报"信号模式"。
- **参数过拟合风险**：多阈值依赖"扩散多日主线"才盈利，鲁棒性待实盘验证；动态板块发现等接口依赖本券商 PTrade 版本，不存在自动降级不报错。

## 八、可照抄的操作节奏（热点）
- **盘前**：T-1 收盘定热点板块（五维共振 + 仅扩散）；动态发现新题材；看宽基 60/120 日线定市场开关（L2 是否降档/禁开）。
- **开盘（09:30）**：确认板块真在动（未确认不开仓）；高开 >2% 放弃；回踩不破开盘价才买。
- **盘中（09:35–10:00 / 10:30）**：滚动扫描窗口回踩买点；每分钟 + 14:58 风控巡检（分批止盈 / 动态移动止盈 / ATR 止损 / 破线 / 退潮）。
- **收盘（15:05）**：尾盘选强（路径B）；打印盈亏台账（胜率 / 回撤 / 最大回撤）。
- **周 / 季**：组合回撤 vs 断路器阈值（-8%/-12%/-18%）；成本预算消耗核对（是否超 7 回合/年）。
