# data 数据目录说明

本目录用于存放**投研工作台网页版（index.html）动态加载展示**的生成内容，如每日晨报、每日复盘等 Markdown 文件。

## 目录用途

- 网页版首页会通过 `fetch('data/YYYY-MM-DD-晨报.md')` 自动加载本目录下的晨报内容并渲染展示
- 网页会自动加载**最新一份**（按日期从当天向前探测，覆盖最近 7 天）晨报，无需手动改代码
- 除晨报外，也可按相同命名规范放置复盘等 Markdown 文档，供网页统一加载展示

## 命名规范

| 文件类型 | 命名规范 | 示例 |
|---------|---------|------|
| 每日晨报 | `YYYY-MM-DD-晨报.md` | `2026-08-31-晨报.md` |
| 每日复盘 | `YYYY-MM-DD-复盘.md` | `2026-08-31-复盘.md` |

## 使用方式

1. 将生成的晨报/复盘 Markdown 文件放入本目录，文件名按上方规范命名
2. 网页版 `index.html` 打开后，左侧导航「投研分析 → 每日晨报」板块会自动加载并渲染最新一份内容
3. 顶部搜索栏输入"晨报"即可快速定位到该板块

## 注意事项

- 文件须为 UTF-8 编码的 Markdown 纯文本
- 若当日晨报尚未生成，网页会回退探测最近日期的晨报；若 7 天内均无文件，则显示"暂无晨报数据"空状态
- 该目录与 `01-投研信息收集/每日晨报/` 归档目录相互独立：归档目录用于长期留存，本目录用于网页实时展示（可放置副本）
