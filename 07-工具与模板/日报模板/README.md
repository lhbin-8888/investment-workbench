# 日报模板

## 用途
存放日报模板文件，用于快速生成每日盘面速览、交易总结和次日计划。

## 推荐文件命名规范
```
模板类型_日报模板_版本号.md / .docx
```
- 示例：`标准版_日报模板_v1.0.md`

## 模板应包含
- 每日盘面速览（三大指数、成交额、板块表现）
- 操作回顾（当日买卖、持仓变动）
- 市场热点与消息面
- 次日关注标的与操作预案
