# 复盘模板

## 用途
存放投资复盘模板文件，涵盖日度/周度/月度复盘的结构化模板。

## 推荐文件命名规范
```
模板类型_复盘模板_版本号.md / .docx
```
- 示例：`日度_复盘模板_v1.0.md`

## 模板应包含
- 市场环境判断（趋势/震荡/熊市）
- 操作执行情况（按计划执行率、偏离原因）
- 盈亏归因（选股/择时/仓位贡献）
- 情绪与心态记录
- 改进措施与行动项
- 下次复盘核验清单
*（内容由AI生成，仅供参考）*
