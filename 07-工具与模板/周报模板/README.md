# 周报模板

## 用途
存放周报模板文件，用于快速生成每周投资总结、绩效分析和下周策略。

## 推荐文件命名规范
```
模板类型_周报模板_版本号.md / .docx
```
- 示例：`标准版_周报模板_v1.0.md`

## 模板应包含
- 本周市场回顾（A股/海外/大宗/资金面）
- 组合表现（绝对收益/相对收益/最大回撤）
- 交易复盘（本周操作、胜率、盈亏分析）
- 关键事件与影响评估
- 下周策略与关注标的
