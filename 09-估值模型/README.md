# 09 估值模型（个股估值模型）

投研工作台「估值模型」板块，提供 **输入个股名称或代码即可自动生成估值报告** 的在线工具。

## 一、功能

- **输入框 + 实时预览**：在页面顶部输入个股名称（如 `中国巨石`）或 6 位代码（如 `600176`），点击「生成报告」，下方即时预览完整估值分析报告。
- **估值逻辑严格遵循「个股估值」技能**：
  1. **判类型**：自动将公司归入 6 类之一（成熟稳定盈利 / 稳定成长 / 亏损高增长 / 强周期 / 重资产·金融 / 无形资产型）。
  2. **选主尺**：按类型选主估值尺（DCF / PE / PEG / PS / PB）。
  3. **两把尺子交叉验证**：至少两种方法印证，划出 **内在价值区间**（悲观情景下限 ~ 中性情景上限）与 **安全边际**。
- **一键生成 PDF 并进入文档列表**：点击「保存到文档列表（生成 PDF）」，自动导出 PDF 并在本板块下方的「文档列表」中登记，HTML 版与 PDF 版同步归档，便于随时回溯。

## 二、估值方法对照

| 公司类型 | 主尺 | 交叉验证 | 典型标的 |
|---|---|---|---|
| 成熟稳定盈利型 | PE + DCF | PE 中枢 / DCF 双情景 | 招行、长江电力 |
| 稳定成长型 | PEG | PEG 合理价 / PE 中枢 | 宁德时代、医美 |
| 亏损高增长型 | PS | 终局净利率×终局PE | 未盈利科技/新能车 |
| 强周期型 | PS + PB | PS 合理价 / PB 合理价 | 中国巨石、宝钢 |
| 重资产/金融型 | PB + 股息率 | PB 合理价 | 银行、保险 |
| 无形资产型 | PE / DCF | 警惕 PB 误判 | 茅台、互联网 |

## 三、数据来源（均无需 API Key）

- **东方财富** `datacenter-web.eastmoney.com` —— 三大财务报表（利润表 / 资产负债表 / 现金流表）、同业、分红。
- **腾讯财经** `qt.gtimg.cn` —— 实时行情、PE(TTM)、总市值、换手率。

## 四、技术架构

- **前端** `vm.html`：纯静态横版页面（输入框 + 预览 iframe + 保存/导出按钮），与「财务分析」板块同风格。
- **后端**：估值引擎 `valuation_engine.py` 的核心函数（取数 / 分类 / 估值 / 渲染 / PDF / 写文档列表）**已并入主服务 8848**，由 `stock_analyzer.py` 统一托管 `/vm/*` 路由——**同源访问，无需独立端口**。
  - `/vm/analyze?code=600176` —— 返回估值报告 HTML（用于预览）。
  - `/vm/save?code=600176` —— 生成 HTML+PDF 并写入 `data/manifest.json` 的「估值模型」分区（用于文档列表）。
  - `/vm/export_pdf?code=600176` —— 直接下载 PDF。
  - （`valuation_engine.py` 仍保留可选的 `--serve 8849` 独立启动方式，作为调试备用，日常无需使用。）

## 五、启动方式

通过工作台总入口 `start.bat` 一键启动主服务（**仅需 8848 一个端口**，自动覆盖估值模型）。
启动后浏览器访问 `http://localhost:8848/index.html` → 左侧「投研研究 → 估值模型」即可使用。

命令行直接出报告（不入文档列表）：

```bash
python 09-估值模型/valuation_engine.py 600176          # 生成 HTML
python 09-估值模型/valuation_engine.py 600176 --pdf      # 同时导出 PDF
python 09-估值模型/valuation_engine.py 中国巨石           # 支持名称输入
```

## 六、命名规范

保存到文档列表的文件命名：`估值模型_{代码}_{简称}_{YYYYMM}.html / .pdf`，标题：`估值报告_{代码}_{简称}_{YYYYMM}`。
