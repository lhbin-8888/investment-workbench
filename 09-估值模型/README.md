# 09 估值模型（个股估值模型）

投研工作台「估值模型」板块，提供 **输入个股名称或代码即可自动生成估值报告** 的在线工具。

> **架构说明（2026-09-17 起）**：本板块已改为 **纯前端** 实现——浏览器直接调公开数据接口、算法在页面内用 JS 运行，**不需要启动任何后端服务或 Python 环境**，本地与线上（纯静态托管）均可直接使用。

## 一、功能

- **输入框 + 实时预览**：在页面顶部输入个股名称（如 `中国巨石`）或 6 位代码（如 `600176`），点击「生成报告」，下方即时预览完整估值分析报告。
- **估值逻辑严格遵循「个股估值」技能**：
  1. **判类型**：自动将公司归入 6 类之一（成熟稳定盈利 / 稳定成长 / 亏损高增长 / 强周期 / 重资产·金融 / 无形资产型）。
  2. **选主尺**：按类型选主估值尺（DCF / PE / PEG / PS / PB）。
  3. **两把尺子交叉验证**：至少两种方法印证，划出 **内在价值区间**（悲观情景下限 ~ 中性情景上限）与 **安全边际**。
- **一键导出 PDF**：报告右上角「导出 PDF」按钮（或直接 Ctrl+P），在浏览器打印对话框中选择「另存为 PDF」即可保存，无需服务端渲染。
- **支持直达链接**：`vm.html?code=600176` 可跳过输入直接出报告，便于外部引用。

## 二、估值方法对照

| 公司类型 | 主尺 | 交叉验证 | 典型标的 |
|---|---|---|---|
| 成熟稳定盈利型 | PE + DCF | PE 中枢 / DCF 双情景 | 招行、长江电力 |
| 稳定成长型 | PEG | PEG 合理价 / PE 中枢 | 宁德时代、医美 |
| 亏损高增长型 | PS | 终局净利率×终局PE | 未盈利科技/新能车 |
| 强周期型 | PS + PB | PS 合理价 / PB 合理价 | 中国巨石、宝钢 |
| 重资产/金融型 | PB + 股息率 | PB 合理价 | 银行、保险 |
| 无形资产型 | PE / DCF | 警惕 PB 误判 | 茅台、互联网 |

## 三、数据来源（均无需 API Key）

- **东方财富** `datacenter-web.eastmoney.com` —— 三大财务报表（利润表 / 资产负债表 / 现金流表）、同业、分红（JSON 接口，浏览器可直接跨域访问）。
- **腾讯财经** `qt.gtimg.cn` —— 实时行情、PE(TTM)、总市值、换手率（GBK 编码，页面内解码）。
- 两处接口均为公开数据、无需注册或密钥；页面为纯前端，不经过任何中转服务器。

## 四、技术架构（纯前端，无后端）

- **`vm.html`（单文件）**：HTML / CSS / JS 全部内联。估值算法为浏览器端 JS 实现——
  - 取数与代码解析：`emQuery()` / `resolveCode()` / `fetchQuote()`（腾讯行情按 GBK 解码）；
  - 分类与估值：`classify()`（6 类判定）、`valueDcf()` / `valuePe()` / `valuePeg()` / `valuePs()` / `valuePb()`；
  - 组装与渲染：`analyzeValuation()`（取三大报表 14 期 → 算每股指标与年报趋势 → 分类 → 主尺 + 只取本类型方法做交叉验证 → 区间）→ `render()`（7 段式报告）。
- **无任何服务端依赖**：使用本页面时不再需要 8848 / 8849 端口、不需要 `/vm/*` 路由、不需要 Python。双击 `vm.html` 即可运行；GitHub Pages 等纯静态托管同样可用。
- **与工作台集成**：`index.html` 通过 iframe（`id="vmFrame"`）内嵌本页；页面用 `postMessage({ type:'vm-resize', height })` 回传内容高度，外层自适应（560 ~ 1400px）。
- **`valuation_engine.py`（保留，可选）**：估值算法的命令行 / 离线参考实现，与前端 JS 逻辑一致，供无浏览器环境或批量离线计算时使用，日常无需启动。
  - 说明：该文件内的 `--serve 8849` 服务模式、以及 `08-财务分析/stock_analyzer.py` 中残留的 `/vm/*` 老路由属**历史遗留**，纯前端版 `vm.html` 已不再调用，保留仅为不影响既有命令行用法。

## 五、使用方式

**本地（推荐）**

- 浏览器直接打开 `09-估值模型/vm.html`；或经工作台总入口 `index.html` → 左侧「投研研究 → 估值模型」进入（入口为纯静态页，浏览器直接打开即可，无需 `start.bat` 起服务）。

**线上**

- 部署在 GitHub Pages 的纯静态版本中，与「财务分析」板块一样可直接打开使用。

**命令行（可选，离线出报告）**

```bash
python 09-估值模型/valuation_engine.py 600176          # 生成 HTML
python 09-估值模型/valuation_engine.py 600176 --pdf      # 同时导出 PDF
python 09-估值模型/valuation_engine.py 中国巨石           # 支持名称输入
```

## 六、命名规范

- 归档文件命名：`估值模型_{代码}_{简称}_{YYYYMM}.html / .pdf`，标题：`估值报告_{代码}_{简称}_{YYYYMM}`。
- 纯前端版导出的 PDF 由浏览器打印对话框保存，文件名可在保存时按上述规范自行填写。
