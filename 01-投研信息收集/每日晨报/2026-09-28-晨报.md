## 五、重点关注方向

1. **半导体自主可控链（存储 / 设备零部件 / 先进封装）**：长鑫第五代 DRAM 量产 + 昇腾 960 超节点 + 半导体零部件订单创新高 + 粤芯超购印证打新热度，机构明确看"科技第二波"，为当前最强主线。
2. **大消费（智能穿戴 / 具身智能机器人 / 以旧换新链）**：中秋假期数据直接兑现（穿戴 +1.2 倍、具身机器人 +93.1%），叠加 9/28 工业企业利润与消费政策预期。
3. **红利防御（银行 / 煤炭 / 高股息）**：节前避险资金偏好 + 险资入市政策 + 上周四领涨结构延续，适合作为防守备选。
4. **油气油服（谨慎、双向）**：特朗普拒绝停火方案 vs 美军协助霍尔木兹通航，多空消息对冲、油价双向波动，只做右侧不追高。

## 六、风险提示

1. **美债利率高位压制**：10 年期美债盘中 5.23% 为 2007 年来最高，若收益率再度上行突破前高，全球成长股估值承压，A 股科技股弹性将被压缩。
2. **美伊地缘反复**：特朗普拒绝停火方案并称考虑军事打击选项，若谈判破裂、油价再度飙升，将推升输入性通胀与避险情绪，压制风险资产。
3. **节前流动性收缩与存量博弈**：本周仅 3 个交易日，今日 6603 亿逆回购 + 6000 亿 MLF 到期，资金观望情绪浓，追高个股易被套；节后风格切换风险需预留余地。
4. **业绩披露分化**：三季报预告进入集中披露期，业绩不及预期个股存在闪崩风险，注意规避纯题材无业绩标的。
5. **反弹无量则二次回踩**：上周四 4300 余家下跌显示内生承接不足，若今日反弹缩量，沪指存在回踩 3850 甚至二次探底的可能。
