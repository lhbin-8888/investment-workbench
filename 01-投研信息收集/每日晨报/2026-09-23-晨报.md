## 二、消息面要点

**1. 政治 / 宏观**
- **习特华盛顿峰会今日开幕（9/23—25）**：应特朗普邀请，习近平主席对美国进行国事访问，为半年内中美元首互访、时隔3年再访美。峰会成果（经贸关税、AI护栏、双边投资）将决定本周全球风险偏好方向，是今日最大正面催化。
- **美联储加息余波未消**：9/17加息25bp至3.75%—4.00%后，芝商所FedWatch显示12月再加息概率约90%、10月至少25bp概率约53%；美债10Y约4.96%，美元指数100.53，持续压制新兴市场汇率（离岸人民币失守6.70）。
- **国内政策暖风**：发改委提出北斗产业5年内规模超1万亿、推介36个民间资本项目（总投资614亿）；央行召开外资金融机构座谈会，强调实施好适度宽松的货币政策、优化营商环境。

**2. 产业 / 科技**
- **AI应用与算力双线催化**：阿里云栖大会9/22开幕（Agentic AI为核心）；亚马逊Bedrock接入开源大模型Kimi K3；国产AI芯片（华为昇腾、寒武纪等）市占率首超60%；华为全联接大会发布昇腾960超节点。
- **资金从AI硬件切向AI软件**：昨日计算机（+34亿）、传媒（+29亿）主力净流入居前，通信（-44亿）、电子（-30亿）净流出居前；出版传媒、算力租赁、AI应用领涨。

**3. 上市公司 / 公告**
- **华瓷股份**晋级6连板（市场高度板），多家"华字辈"跟风；**哈药股份、新华制药、华仁药业**走出2连板（医药线）。

**4. 隔夜外盘要点**

## 三、当日走势研判

**方向性判断：高开、震荡、结构性分化。**

- **高开依据**：习特峰会开幕释放风险偏好、油价跌破百元缓解通胀压力、隔夜纳指续创新高、亚太市场普涨（日经+1.38%、KOSPI+1.28%）。

## 四、关注方向

1. **AI应用 / 传媒 / 算力租赁**（延续性首选）

2. **国产算力 / 半导体硬件链（CPU、算力芯片、先进封装、AI芯片）**（中线回流）
   华为昇腾960超节点 + 国产AI芯片市占率首超60% + 机构测算存储/半导体拥挤度处历史底部。昨日硬件方向高开低走、资金流出，若今日企稳有望回流。

3. **北斗导航 / 卫星**（政策主题）
   发改委明确北斗产业5年内规模超1万亿，顶层政策催化确定，关注芯片、终端、高精度定位与时空信息服务链条。

4. **低位防御：煤炭 / 汽车整车**（对冲高位分歧）
   昨日煤炭+1.18%、主力净流入约4亿（大有能源涨停）；汽车整车连续8日获主力净流入。在AI方向分歧加大时具防御与轮动价值。

## 五、风险提示

1. **美联储再加息与流动性收紧**：12月加息概率约90%、美债10Y高位4.96%、美元指数100.5，全球流动性收紧压制A股估值与新兴市场汇率，离岸人民币已失守6.70，需警惕北向情绪与外盘波动传导。
2. **A股内在分歧与量价背离**：昨日放量至2.14万亿但超3000只个股下跌，连续反弹后获利盘兑现压力明显；若今日量能无法维持在2万亿上方，指数冲高回落风险较大。
3. **习特峰会结果不确定性**：经贸/关税/AI护栏成果若不及预期，风险偏好可能快速回落；中东美伊博弈反复，油价跌破百元后仍有反弹风险，扰动通胀与风险资产。
4. **长假前资金谨慎**：9/23日本秋分休市，临近国庆长假，假期前资金趋于谨慎，题材持续性需竞价确认，切忌追高日内高潮板块。
